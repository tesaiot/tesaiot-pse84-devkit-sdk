# ===== GENERIC 2-char clusters (above-vowel + mark) =====
# Replaces the prior per-consonant explosion. Key insight (อาจารย์'s):
# Thai combining marks in NotoSansThai have heavily-negative LSB
# (uni0E35 lsb=-514, uni0E48 lsb=-178 etc.) so their bitmap pixels naturally
# draw to the LEFT of the glyph origin. HarfBuzz also shapes orphan
# "<above-vowel><mark>" sequences correctly WITHOUT inserting a dotted
# circle — emitting just the two marks with the proper y_offset
# (236 for ี/ื, 179 for ั, 177 for ิ — 2nd-tier stacking).
#
# So we make ONE generic PUA composite per (above-vowel, mark) pair, with
# total_advance = 0 (combining behavior). When the runtime substitutes
# "<consonant>ี่" -> "<consonant>" + PUA(ี่), LVGL renders the consonant at
# its normal width then draws PUA(ี่) with negative LSB → marks overlay the
# consonant. Works for ALL 44 Thai consonants automatically.
#
# Longest-first matching means 3-char specifics above (ที่, นี้ etc.) still
# take precedence for the few words where we want HarfBuzz's exact per-
# consonant positioning. Falls through to generic for everything else.
# ี + 4 tones + thanthakhat + mai-tai-khu (some may be skipped if TTF can't)
