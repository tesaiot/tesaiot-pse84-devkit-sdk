bool optiga_check_certificate_validity ( uint16_t oid,
cert_validation_result_t * result )

Check certificate validity and extract information.

Reads certificate from OPTIGA Trust M and validates it against current time. Extracts subject, issuer, validity dates and calculates days until expiry.

Parameters
oidCertificate OID (0xE0E0 for Factory, 0xE0E1 for Device)
resultPointer to validation result structure (output)
Returns
true if certificate readable and parseable, false on error
Note
Requires RTC or NTP time synchronization for accurate validation
Uses mbedtls_x509_crt_parse() for X.509 certificate parsing

◆ test_metadata_operations()

optiga_lib_status_t test_metadata_operations ( void )

Test metadata operations for debugging certificate write issues

Performs 5 comprehensive diagnostic tests:

  • TEST 1: Read metadata from OID 0xE0E1 (device certificate slot)
  • TEST 2: Test write metadata to OID 0xF1D0 (user data OID)
  • TEST 3: Display OID 0xE0E1 specification (access conditions from datasheet)
  • TEST 4: Read Global Lifecycle State (OID 0xE0C0) to check if device is locked
  • TEST 5: Read and display current device certificate from OID 0xE0E1

Certificate Display includes:

  • Subject CN (Common Name)
  • Issuer CN
  • Valid From/To dates
  • Serial Number
  • Certificate size
  • First 64 bytes of DER data

Usage: Run before CSR workflow to see OLD certificate, then after to see NEW certificate

Returns
OPTIGA_LIB_SUCCESS on success, error code otherwise
