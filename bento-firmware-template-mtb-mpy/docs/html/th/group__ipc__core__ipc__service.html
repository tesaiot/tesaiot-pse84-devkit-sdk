bool ipc_service_init ( void )

การเริ่มการทำงานของ service task — ลำดับที่สามใน boot prologue

Initialize the IPC service. Creates queue, registers IPC callback, starts handler task. Must be called after cm55_ipc_communication_setup() and wifi_manager_init().

Returns
true on success
