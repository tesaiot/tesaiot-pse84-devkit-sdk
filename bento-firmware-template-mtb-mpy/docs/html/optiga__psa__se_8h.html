void optiga_psa_set_signing_key_oid ( optiga_key_id_t oid)

Set the OPTIGA key OID to use for TLS signing.

Parameters
oidKey OID (0xE0F0 for factory cert, 0xE0F1 for TESAIoT cert)

Call this BEFORE psa_generate_key() to select which key to use. Must match the certificate being used:

  • Certificate 0xE0E0 (factory) -> Key 0xE0F0
  • Certificate 0xE0E1 (TESAIoT) -> Key 0xE0F1
