Detailed Description

Six functions: the nus_agent_* stream handlers. Compiled only with ENABLE_PAGE_BENTO_BUDDY=1 (default 0, proj_cm33_ns/Makefile:64, :305); rebuild after make getlibs — Flag gate (read first).

Declarations: nus_agent.h (includes vendor/jsmn.h, absent from the dist include set — Header packaging note). Implementation nus_agent.c is archived in libbento_secure.a. Module state is a single in-flight ask owned by one NUS RX task (nus_agent.c:44): token frames whose id does not match the latest ask are silently dropped; the accumulator is bounded at 256 chars and overflow truncates.

Variant
mtb-mpy and mtb-only

◆ nus_agent_note_ask()

void nus_agent_note_ask ( const char * id)

Record the in-flight ask id; a NULL or empty id resets the agent. No caller anywhere.

Contract
Records the in-flight ask id so later token/done frames can be matched; ids longer than the internal buffer are truncated. A NULL or empty id resets the agent (nus_agent.c:122-133 — cited as the definition, not a call). No caller anywhere; the definition rendered under nus_agent_reset() shows the id-copy semantics.
Variant
mtb-mpy and mtb-only
Example (authored — no shipped call site)
__attribute__((used))
static void bento_ex_nus_agent_note_ask(void)
{
/* Arm for the ask we are about to emit: */
nus_agent_note_ask("ask-42");
/* ...emit the bento.agent.ask event with the same id; token/done
* frames carrying any other id are now silently dropped. */
/* Leaving the ASK submode? NULL (or "") resets the accumulator: */
nus_agent_note_ask(NULL);
}
