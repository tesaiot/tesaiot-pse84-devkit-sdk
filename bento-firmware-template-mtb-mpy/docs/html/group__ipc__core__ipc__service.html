Detailed Description

Header: ipc_service.h. Implementation: archived ipc_service.c (libbento_ipc.a). The bidirectional WiFi/MQTT/TESAIoT command service: receives service commands from CM33_NS, processes them in its own FreeRTOS task and writes responses to shared memory for CM33_NS to poll.

Variant
mtb-mpy and mtb-only

bool ipc_service_init ( void )

Service task bring-up — third in the boot prologue.

Initialize the IPC service. Creates queue, registers IPC callback, starts handler task. Must be called after cm55_ipc_communication_setup() and wifi_manager_init().

Returns
true on success
Contract
"Must be called after \c cm55_ipc_communication_setup() and \c wifi_manager_init()" (ipc_service.h). The archived display controller calls it third in the boot prologue, immediately after ipc_sensorhub_init() and before GFXSS bring-up, so the service survives a display failure. Creates the queue, registers the IPC callback and starts the handler task. Consumers using the shipped display controller never call it.
Variant
mtb-mpy and mtb-only
