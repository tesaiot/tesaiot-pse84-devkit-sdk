Detailed Description

mpy_secure is libbento_mpy.a: the BentoClaw agent (safety, session, HTTPS transport), the TACP control protocol, the WiFi credential store, the transport-agnostic model link and the two archived MicroPython modules. The archive links only under BENTO_HAS_MPY=1 — on the mtb-only path the module contributes zero symbols, except the six lfs_wifi_creds_* names, which the mtb-only build re-provides as shipped source (storage_c/lfs_wifi_creds_c.c) and which are therefore marked "mtb-mpy and mtb-only" below.

No implementation file of this module ships in the template; only the headers do. Every example on these pages is either real shipped consumer code (the .c files under template/bento_libs/claw/common/mpy, quoted by \snippet) or an authored example explicitly labelled as having no shipped call site. Eight of the 46 are authored.

Four exported symbols have no declaration in any shipped mpy_secure header (bento_secure_undeclared.h records each): mp_module_optiga and mp_module_edge_ai (Module registrations), bento_link_ipc_query (bento_link_ipc_query) and optiga_verify_staged_model (OPTIGA verify — WEAK; its prototype ships in the tesaiot_hsm module). With no declaration for \fn documentation to attach to, they are documented as notes, not function entries — the same rule the Edge AI module applies to its printf/puts link hazard.
