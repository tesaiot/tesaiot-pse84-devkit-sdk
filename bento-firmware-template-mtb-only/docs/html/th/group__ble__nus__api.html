Detailed Description

คู่มืออ้างอิง BLE ของ Bento Desktop Buddy — 87 symbol ครบตามรายการใน dist/ble_nus/api.txt

Flag gate (อ่านก่อน)

symbol ทุกตัวในโมดูลนี้ถูกคอมไพล์ออกไปจาก build ค่าตั้งต้น: ENABLE_PAGE_BENTO_BUDDY ?= 0 (proj_cm33_ns/Makefile:64, :305) บล็อกที่นำ BLE ขึ้นใน proj_cm33_ns/main.c รวมทั้งข้อความ [boot] Asserting WL_REG_ON ที่พิมพ์ออกมา อยู่ภายใน #if ENABLE_PAGE_BENTO_BUDDY (main.c:36, :325) ทุกตัวอย่างและทุกขั้นตอนการตรวจสอบในหัวข้อเหล่านี้ตั้งอยู่บนสมมติฐานว่าได้ build ใหม่ด้วย ENABLE_PAGE_BENTO_BUDDY=1 หลังจาก make getlibs แล้ว Makefile จะหยุดด้วย $(error ...) ที่ :353-359 ถ้าไม่มีไลบรารี BT อยู่ โมดูลนี้เป็น "ทั้งสอง variant" เฉพาะในความหมายของ BENTO_HAS_MPY เท่านั้น — สิ่งที่ตัดสินว่าโมดูลนี้มีอยู่หรือไม่คือ flag ไม่ใช่ variant
