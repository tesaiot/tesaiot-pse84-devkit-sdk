Detailed Description

ฟังก์ชัน 5 ตัวสำหรับ set — คือโมเดลหลายตัวที่ฟังข้อมูลเซนเซอร์ชุดเดียวกัน ส่วนค่าคงที่ การแปลงค่ารูปเดิม 13/14/15 และข้อเท็จจริงที่หลีกไม่ได้ 2 ข้อ (ALL ไม่มี slot ให้นิยามได้; ai_engine_snapshot() ทำให้การตรวจพบหายไปเมื่ออยู่ใน set) อยู่ที่ ดัชนีเทียมของ set และการแปลงค่ารูปเดิม

variant ที่ใช้ได้
mtb-mpy และ mtb-only

ข้อกำหนดการเรียกใช้
เขียนรายชื่อสมาชิกของ set ใด ๆ ตามลำดับใน registry และคืนค่าเป็นจำนวนที่เขียนได้ (คืน 0 สำหรับดัชนีที่ไม่ใช่ set) ลำดับความสำคัญ: สมาชิกภาพที่กำหนดไว้อย่างชัดแจ้งผ่าน ai_engine_set_define() ชนะขาด รายการจับคู่ชื่อที่คอมไพล์มา (ai_engine.c:1146-1149) การคลี่หาสมาชิกถูกสร้างใหม่ทุกครั้งที่เข้าสู่ set นั้น ไม่มีการแคชไว้ โมเดลที่ init() ล้มเหลวไปครั้งหนึ่งจึงไม่ถูกตัดออกไปตลอดรอบการบูต ภายในหนึ่งรอบเรนเดอร์ ให้อ่านค่า ai_engine_active() เพียงครั้งเดียว แล้วส่งค่านั้นเข้ามาที่นี่ — deepcraft task อาจสั่ง start/stop จาก task อื่นกลางรอบเรนเดอร์ได้ และการอ่านซ้ำจะทำให้ set ที่ใช้ตั้งป้ายเลย์เอาต์ไม่ตรงกับ set ที่ใช้คำนวณจำนวนแถว

Registry indices of the ACTIVE SET's members, up to max, whatever sensor each one reads – not microphone models. Returns the count. Callers that iterate this must test desc->sensor before doing anything sensor-specific with an entry.

ข้อกำหนดการเรียกใช้

int ai_engine_set_define ( uint32_t set_index,

uint32_t n )

กำหนดสมาชิกภาพแบบชัดแจ้งให้ set ณ เวลาทำงาน; ต้องอยู่ใน task context และเป็นแบบทั้งหมดหรือไม่เอาเลย

Give a set an explicit membership at run time, replacing the compiled one. Task context. Undefined sets keep their compiled membership exactly.

ข้อกำหนดการเรียกใช้
กำหนดสมาชิกภาพแบบชัดแจ้ง ณ เวลาทำงานให้ set หนึ่ง แทนที่สมาชิกภาพที่คอมไพล์มา เรียกได้จาก task context เท่านั้น — ตัวฟังก์ชันจับ taskENTER_CRITICAL() คร่อมการเผยแพร่ค่า (ai_engine.c:1059-1075) สมาชิก 1..8 ราย ทั้งหมดหรือไม่เอาเลย: ทุกดัชนีถูกตรวจสอบ และดัชนีที่ผิดเพียงตัวเดียวทำให้ปฏิเสธการนิยามทั้งชุด AI_PARALLEL_ALL (252) ไม่มี slot — การเรียกจะคืนค่า -1 เสมอ สำหรับค่านั้น (set_slot(), ai_engine.c:1040-1048, จับคู่เฉพาะ INTRUDER/ROOM/MIC) ไม่มี ack event: การตอบรับอย่างเดียวที่มีคือการอ่านค่ากลับด้วย ai_engine_set_members_defined() ฝั่ง MicroPython edge_ai.set_define() ขับสิ่งนี้เป็นการสร้างด้วย 3 คำสั่ง (SET_BEGIN, SET_ADD หนึ่งครั้งต่อสมาชิกหนึ่งราย เว้นจังหวะที่ 5 ms, SET_COMMIT) แล้วนำไปใช้ทั้งชุดตอน commit — ADD ที่ตกหล่นจะถูกจับได้ด้วยการอ่านกลับ Q_SET เท่านั้น เหตุที่ต้องมีฟังก์ชันนี้: set ที่คอมไพล์มาจับคู่ด้วยชื่อ โมเดลที่ staged (อัปโหลดเข้ามา) จึงเข้าร่วมการเฝ้าระวังได้ทางการนิยามแบบชัดแจ้งเท่านั้น (ai_engine.c:1092-1127)
