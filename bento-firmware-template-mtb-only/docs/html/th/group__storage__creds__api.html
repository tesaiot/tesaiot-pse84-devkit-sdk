 ที่เก็บข้อมูลรับรอง WiFi
 สอง implementation หนึ่งข้อกำหนดบนดิสก์

Detailed Description

คู่มืออ้างอิงของที่เก็บข้อมูลและข้อมูลรับรอง: ฟังก์ชัน lfs_wifi_creds_* ทั้ง 6 ตัว พร้อมตัวอย่างประกอบที่อ้างถึง storage_c/lfs_wifi_creds_c.c และ sensor_auto_task.c — ทั้ง 2 ไฟล์นี้ zip ของ mtb-only ส่งมอบมาเป็นซอร์ส คู่มืออ้างอิงชุดนี้จัดวางไว้ที่นี่ ใต้ที่เก็บข้อมูลและข้อมูลรับรอง บนเว็บไซต์ของ variant ทั้งสอง ที่ URL เดียวกัน (RED_IA_REVIEW P1-6; ส่วน mpy_secure เชื่อมโยงข้ามมาที่นี่แทนการมีสำเนาของตนเอง) แผงสอง implementation (implementation ที่อยู่ใน archive — ไฟล์ไลบรารีแบบสแตติก .a — เทียบกับ lfs_wifi_creds_c.c) โดยมีรูปแบบข้อมูลบนดิสก์ที่เข้ากันได้ระดับไบต์เป็นข้อกำหนดร่วม อยู่ที่ สอง implementation หนึ่งข้อกำหนดบนดิสก์

บน mtb-only ไม่มีการลิงก์ libbento_mpy.a และโมดูล mpy_secure ไม่ให้ symbol ใดเลย ชื่อทั้งหกนี้เป็นข้อยกเว้นเดียว โดยที่เก็บฝั่ง C ที่ส่งมอบจริงจัดหาชื่อเหล่านี้ให้ใหม่ บน mtb-mpy ชื่อทั้ง 6 ชุดเดียวกันมาจาก lfs_wifi_creds.c ที่อยู่ใน libbento_mpy.a ส่วน implementation ฝั่ง C ที่ส่งมอบจริงยกมาทั้งหมดไว้บนหน้าคู่มืออ้างอิง — สั้นพอที่จะเป็นข้อกำหนดของตัวเองได้
