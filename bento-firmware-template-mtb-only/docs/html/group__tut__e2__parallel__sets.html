Learning goal

Run several models at once as a set, read a verdict from the set without losing detections, and recognise the settle gate that withholds verdicts while the audio windows fill. The single most important sentence: ai_engine_snapshot() is not valid inside a parallel set.

Real firmware sequence

Set constants (ai_engine.h:97-113): MIC = 255, ROOM = 254, INTRUDER = 253, ALL = 252, AI_PARALLEL_FIRST = ALL. The legacy 13/14/15 aliases resolve to 253/254/255 (Chapter E1). An archive that predates ALL rejects 252 on hardware (ai_engine.h:109-113). Engine acceptance of any set index requires EDGE_AI_HAS_MIC (ai_engine.c:1850-1859).

Entering a set rebuilds membership on every entry (set_resolve(), ai_engine.c:1166-1189): explicit membership from set_define wins outright, otherwise the compiled name-match (set_wants(), ai_engine.c:1092-1127). Nothing is cached, so a model whose init() failed once is not exiled for the boot. Explicit-wins precedence is at ai_engine.c:1146-1149.

Custom membership — edge_ai.set_define(set, [i, j, ...]) (modedgeai.c:867-921): resolve the legacy index (:876), SET_BEGIN (:886), one SET_ADD per member paced at 5 ms (:895-902), SET_COMMIT (:904), 40 ms settle (:907), then a Q_SET read-back (:910) — the read-back is the only thing that catches a dropped ADD. Step by step

Step 1 — Enumerate the sets the page offers (both variants)

On screen, open the model dropdown on the Edge AI page. Rows for sets are added only when the set has at least two members and a name:

What you should observe. Set rows (Sound Watch, Room Presence, Intruder Watch, All Models) appear after the compiled single models. A set with fewer than two resolvable members is simply absent — that is a build-content fact, not a fault.

Step 2 — Select a set and watch the settle gate

>>> edge_ai.select(255) # MIC set; 15 is the legacy alias
True
>>> edge_ai.result()
>>> edge_ai.result()

What you should observe. For the first seconds result() returns None — class_count == 0 — while the audio windows fill. On screen the verdict label reads filling windows lu%% with the percentage climbing (page_edge_ai.c:698-699), and the badge shows CHIP_LOADING. The gate is ai_engine_mic_settling() / ai_engine_mic_settle_pct():

Step 4 — Define your own membership

>>> edge_ai.set_define(253, [0, 2])
>>> edge_ai.select(253)
True

What you should observe. set_define returns after the Q_SET read-back confirms every member; a dropped ADD shows up as a shorter list, and the whole definition is refused if any index is invalid (all-or-nothing, ai_engine.c:1060-1064). Membership is 1..8 entries. set_define(252, ...) always fails — AI_PARALLEL_ALL has no slot (set_slot(), ai_engine.c:1040-1048).

Traps

Warning
The snapshot-in-set hazard. ai_engine_snapshot() is last-writer-wins over one slot. In a set, "a cough detected at 0.94 is overwritten by three 'unlabelled' … The detection is not late, it is gone" (ai_engine.c:1876-1885). Use ai_engine_snapshot_model() per member and reduce. The branch that decides between the two was == AI_PARALLEL_MIC until 2026-08-09, so Room Presence and Intruder Watch fell into exactly the slot the branch exists to avoid (deepcraft_task.c:448-450) — the correct test is the range [AI_PARALLEL_FIRST, AI_PARALLEL_MIC].
set_define is task context only. It takes taskENTER_CRITICAL around the publish (ai_engine.c:1059-1075); never call it from the pipe callback.
