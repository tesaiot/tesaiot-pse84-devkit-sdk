Detailed Description

Nine functions: sensor_stream_* and voice_capture_*. Compiled only with ENABLE_PAGE_BENTO_BUDDY=1 (default 0, proj_cm33_ns/Makefile:64, :305); rebuild after make getlibs — Flag gate (read first).

Declarations: sensor_stream.h, voice_capture.h. Implementation sensor_stream.c / voice_capture.c is archived in libbento_secure.a. voice_capture is a stub by its own header: the real PDM-PCM path is not wired; it emits one synthetic second of silence as bento.voice.chunk frames so the desktop parser can be validated end to end.

Variant
mtb-mpy and mtb-only
