# cycfg_connectivity_bt.h

Minimal stub of the Bluetooth Configurator output expected by cybsp_bt_config.c. Defines low-power mode flag and version macros that the BSP glue includes at build time. In a full ModusToolbox flow this file is generated by the Bluetooth Configurator GUI from a .cybt design. Since we describe the NUS GATT DB manually in nus_gatt_db.{c,h}, this stub only needs to satisfy BSP compilation. Scope: proj_cm33_ns build only, guarded by COMPONENT_WICED_BLE.

> Configuration header — constants and macros only, no functions.
