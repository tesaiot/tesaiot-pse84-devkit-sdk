◆ ai_engine_snapshot()

bool ai_engine_snapshot ( ai_result_t * out)

Copy the latest published result; last-writer-wins — not valid inside a set.

Copy the latest result. Returns false if nothing has been published yet.

Contract
Copies the latest published result; false if nothing has been published yet. It is last-writer-wins and therefore not valid inside a parallel set — "a cough detected at 0.94 is overwritten by three 'unlabelled' … The detection is not late, it is gone" (ai_engine.c:1876-1885). The shipped code branches on ai_engine_active() being in [AI_PARALLEL_FIRST, AI_PARALLEL_MIC] and uses ai_engine_snapshot_model() per member in that case; deepcraft_task.c:448-450 records that the test was == AI_PARALLEL_MIC until 2026-08-09, so Room Presence and Intruder Watch fell into the very slot the branch exists to avoid. Reduce a result with ai_result_top_positive() — ai_result_t has no valid/label/confidence field (Header facts that are easy to get wrong).
Variant
mtb-mpy and mtb-only

◆ ai_engine_snapshot_model()

bool ai_engine_snapshot_model ( uint32_t index,
ai_result_t * out )

One model's last verdict — the reader to use inside a parallel set.

One model's last verdict. Use this, not ai_engine_snapshot(), whenever several models may be publishing: that one reports whoever wrote most recently, so three quiet models can bury a detection before it is read. False if that model has never published.

Contract
One model's last verdict. Use this in sets. False means "this model has never published" — which is not the same as "silent" (a member that published once and then went quiet still returns true with a stale seq; the page derives a per-row silence timer from seq staleness, page_edge_ai.c:728-739). index must be a real registry index, never a set pseudo-index — obtain members from ai_engine_set_members() (active set) or ai_engine_set_models() (any set).

Registry entry (NULL if out of range).

Contract
Registry entry, NULL if out of range — and NULL for a set pseudo-index. Branch on idx >= AI_PARALLEL_FIRST first and walk the set's members with ai_engine_set_models() before touching a descriptor. Descriptors and the strings they point at stay valid for the life of the boot (slots are never reused). ◆ ai_engine_mic_settling()

bool ai_engine_mic_settling ( void )

True while a parallel set is still filling its windows; verdicts are withheld.

True while the parallel set is still filling its windows. Verdicts are withheld until then; show it rather than four silent zero bars.

Contract
True while a parallel set is still filling its windows; verdicts are withheld until then. Show progress rather than four silent zero bars — and keep the stats line updating during the settle, otherwise an NPU stall inside the window is invisible (page_edge_ai.c:702-705). Keyed on s_current being in [AI_PARALLEL_FIRST, AI_PARALLEL_MIC] (ai_engine.c:1968-1976); false outside a set.
