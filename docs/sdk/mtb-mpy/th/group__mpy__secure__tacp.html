Detailed Description

6 ฟังก์ชัน: เป็นโปรโตคอลควบคุมฝั่ง UART ที่ BENTO IDE ใช้คุยกับบอร์ด (magic 0xAA 0x55, คำสั่งควบคุม, การโอนไฟล์แบบไบนารี และ sub-protocol 0x30 ของ BentoClaw) เขียนไว้ใน tacp.c คอมไพล์รวมอยู่ใน libbento_mpy.a ไม่ได้ส่งมอบมาเป็นซอร์ส เทมเพลตส่งมอบ tacp.h มาให้

4 ตัวมี call site อยู่จริงในของที่ส่งมอบ (ใน mpy_main.c, modui.c, modsensors.c, modbentoclaw.c และ sensor_auto_task.c) ส่วนอีก 2 ตัว คือ tacp_ring_buf_read() และ tacp_ring_buf_readable() ไม่มีผู้เรียกที่ใดเลย: ในเฟิร์มแวร์ที่ส่งมอบจริง REPL ของ MicroPython กิน ring อยู่ภายใน ตัวอย่างของทั้งสองเป็นตัวอย่างที่เขียนขึ้นเองและกำกับไว้

variant ที่ใช้ได้
mtb-mpy เท่านั้น (ไม่มีการลิงก์ libbento_mpy.a เมื่อ BENTO_HAS_MPY=0)

Initialize TACP state machine and ring buffer.

ข้อกำหนดการเรียกใช้
รีเซ็ต state machine ของ TACP ล้าง ring buffer และระบาย FIFO ของ UART ถูกเรียก ครั้งเดียวต่อหนึ่ง soft reset ที่ label soft_reset ของ MicroPython task ไบต์ค้างจากก่อนรีเซ็ตจึงถูกนำมา parse ซ้ำจนเกิดการรีเซ็ตซ้อนสองครั้งไม่ได้ ต้องเรียกก่อนฟังก์ชัน TACP ตัวอื่นทุกตัวในกลุ่มฟังก์ชันนี้ — tacp_poll_uart() ระหว่างการเริ่มต้นระบบปลอดภัยได้ก็เพราะ tacp_init() ทำงานไปก่อนแล้วเท่านั้น ทำงานใน MicroPython task context; เป็น void

bool tacp_poll_uart ( void )

pump UART; ต้องเรียกจากลูปรอแบบบล็อกทุกลูป

Poll UART for TACP commands and REPL bytes. Returns true if a command was detected.

ข้อกำหนดการเรียกใช้
pump UART: กินไบต์ที่มีอยู่ เดิน state machine ของ TACP และผลักไบต์ของ REPL เข้า ring ต้องเรียกจากลูปรอแบบบล็อกทุกลูป ใน MicroPython task context มิฉะนั้น Ctrl-C, ปุ่ม Stop ของ IDE และการอัปโหลดไฟล์จะใช้ไม่ได้ตลอดช่วงที่รออยู่ tacp_init() ต้องทำงานมาก่อน ครั้งเดียวต่อหนึ่ง soft reset ค่าที่คืนมาถูกทิ้งโดยเจตนาที่จุดเรียกทั้ง 7 แห่งในของที่ส่งมอบจริง — มันคือ pump ไม่ใช่ predicate รูปแบบมาตรฐานจับคู่มันกับ MICROPY_EVENT_POLL_HOOK ส่วนรูปแบบฝั่ง FreeRTOS จับคู่กับ vTaskDelay(pdMS_TO_TICKS(1)) แทน ไม่มีการจับ lock ไม่ปลอดภัยต่อการเรียกจาก ISR — ดู tacp_request_delete_main_from_isr() สำหรับทางออกฉุกเฉินทางเดียวเมื่อสคริปต์ที่หลุดการควบคุมทำให้ pump นี้ไม่ได้ทำงาน

◆ tacp_request_delete_main_from_isr()

void tacp_request_delete_main_from_isr ( void )

ทางออกฉุกเฉินที่เรียกจาก ISR ได้: หยุดสคริปต์, สั่ง soft reset, ลบ /main.py

ISR-safe trigger for the CM55 "Delete main.py" button. Breaks a running / looping script (keyboard interrupt) and forces a MicroPython soft reset so the boot path removes /main.py. Safe to call from interrupt context.

ข้อกำหนดการเรียกใช้
เรียกจาก ISR ได้อย่างปลอดภัย: หยุดสคริปต์ที่กำลังทำงาน (keyboard interrupt) และบังคับให้ MicroPython ทำ soft reset เพื่อให้เส้นทางบูตลบ /main.py ทิ้ง ไม่มีการจองหน่วยความจำ ไม่มี hard reset; แฟล็กใน SRAM อยู่รอดข้าม soft reset นี่คือ ทางสำรองสำหรับกรณีที่ลูปใน /main.py หลุดการควบคุมจนยึด CPU ไว้ผู้เดียวและทำให้ tacp_poll_uart() ไม่ได้ทำงาน — เส้นทางแบบนุ่มนวล (s_delete_pending ซึ่งวนถามใน task context) ยังคงมีอยู่เคียงกัน ถูกเรียกจาก IPC ISR ของการควบคุมเซนเซอร์บน CM33_NS โดยมี BENTO_HAS_MPY เป็น guard: บน variant mtb-only ไม่มี VM และไม่มี /main.py ให้ลบ guard จึงคอมไพล์การเรียกนั้นทิ้งไป เป็น void
variant ที่ใช้ได้
mtb-mpy เท่านั้น (ไม่มีการลิงก์ libbento_mpy.a เมื่อ BENTO_HAS_MPY=0)
ตัวอย่าง
callback ของ IPC ISR ใน sensor_auto_task.c
/* ...context: inside the sensor-ctrl IPC ISR callback ... */
if (msg->cmd == IPC_CMD_DELETE_MAIN_PY) {
/* Graceful path: polled by tacp_poll_uart() in task context (works when
* the MP loop is alive, e.g. at the REPL). */
s_delete_pending = true;
/* Robust path: break the script + force a MicroPython soft reset DIRECTLY
* from this IPC ISR, so the Delete button works even when a runaway
* /main.py loop monopolises the CPU and starves tacp_poll_uart(). The
* soft reset keeps SRAM (s_delete_main_flag) intact -> boot removes
* /main.py. ISR-safe (no allocation, no hard reset). Ported from
* Game-libraries 8a0689a (HW-verified on Eva). */
#if BENTO_HAS_MPY
tacp_request_delete_main_from_isr();
#endif /* no VM: there is no /main.py to delete */

ส่งเฟรมคำตอบไบนารีของ BentoClaw หนึ่งเฟรมออกทาง UART

Send a BentoClaw TACP binary response frame. Frame: [0xAA][0x55][0x30][sub_cmd][len_lo][len_hi][payload][crc_lo][crc_hi] Use sub_cmd matching request for success, TACP_CLAW_ERROR (0xFF) for errors.

ข้อกำหนดการเรียกใช้
ส่งเฟรมคำตอบไบนารีของ BentoClaw หนึ่งเฟรมออกทาง UART (0xAA 0x55 0x30, sub-command, ความยาว, payload, CRC-16/CCITT) ให้ใช้ sub_cmd ของคำขอสำหรับกรณีสำเร็จ และใช้ TACP_CLAW_ERROR (0xFF) สำหรับข้อผิดพลาด ต้องเรียก tacp_init() มาก่อน payload_len คือความยาวจริง — ค่าที่ snprintf คืนมาแล้ว cast เป็น uint16_t — ห้ามใช้ strlen ของบัฟเฟอร์ที่อาจถูกตัดทอนไปแล้ว โค้ดในของที่ส่งมอบจริงไม่เคยเรียกฟังก์ชันนี้ตรง ๆ: เรียกผ่าน wrapper claw_respond / claw_respond_err เสมอ เฟรม TACP_CLAW_READY ที่ส่งขึ้นเองโดยไม่มีคำขอจะถูกส่ง ก็ต่อเมื่อ tacp_init(), mp_init(), การเมานต์ VFS และ boot.py / main.py ทำงานจบแล้วเท่านั้น IDE จึงไม่มีทางเห็น READY จากบอร์ดที่ยังรับคำขอไม่ได้ เป็น void ไม่มีเส้นทางแจ้งข้อผิดพลาด; ทำงานใน MicroPython task context ตัวตอบภายในของ archive อีก 20 ตัวใน tacp.c ไม่ใช่ส่วนที่ผู้ใช้ไลบรารีเรียกได้ — ส่วนที่ผู้ใช้ไลบรารีเรียกได้ในของที่ส่งมอบจริงคือจุดเรียก 3 แห่งใน modbentoclaw.c พอดี

int tacp_ring_buf_read ( void )

ดึงไบต์ของ REPL ออกมาหนึ่งไบต์ หรือคืน -1 เมื่อว่าง ไม่มีผู้เรียกที่มีอยู่จริงในของที่ส่งมอบ

Read one byte from the ring buffer (for REPL consumption). Returns -1 if empty.

ข้อกำหนดการเรียกใช้
ดึงไบต์ของ REPL ออกจาก ring หนึ่งไบต์ (0 ถึง 255) หรือคืนค่า -1 เมื่อว่าง ring จะเติมก็ต่อเมื่อ tacp_poll_uart() ทำงานอยู่เท่านั้น — ให้ pump ก่อน tacp_init() ครั้งเดียวต่อหนึ่ง soft reset; ทำงานใน MicroPython task context; มีผู้อ่านได้รายเดียว ไม่มีผู้เรียกที่มีอยู่จริงในของที่ส่งมอบ — ในเฟิร์มแวร์ที่ส่งมอบจริง REPL กิน ring อยู่ภายใน archive; ตัวนิยาม (tacp.c) ไม่ได้ส่งมอบมาเป็นซอร์ส
variant ที่ใช้ได้
mtb-mpy เท่านั้น (ไม่มีการลิงก์ libbento_mpy.a เมื่อ BENTO_HAS_MPY=0)
ตัวอย่าง (เขียนขึ้นเอง — ไม่มี call site ในของที่ส่งมอบจริง)
__attribute__((used))
static void bento_ex_tacp_ring_buf_read(void)
{
/* Pump first — the ring only fills while tacp_poll_uart() runs.
* The return value is deliberately discarded at all shipped pump
* sites: it is a pump, not a predicate. */
(void)tacp_poll_uart();
int c;
while ((c = tacp_ring_buf_read()) >= 0) {
/* consume the byte (REPL character, 0..255) */
(void)c;
}
/* c == -1: ring empty — return to the wait loop and keep pumping. */
}

variant ที่ใช้ได้

ตัวอย่าง (เขียนขึ้นเอง — ไม่มี call site ในของที่ส่งมอบจริง)

static void bento_ex_tacp_ring_buf_readable(void)
{

return; /* nothing buffered — no work */
}

* true readable() in this
* single-consumer context */
(void)c;
}
