Detailed Description

mpy_secure คือ libbento_mpy.a ประกอบด้วย agent ของ BentoClaw (safety, session, HTTPS transport), โปรโตคอลควบคุม TACP, ที่เก็บข้อมูลรับรอง WiFi, model link ที่ไม่ผูกกับ transport ใดเป็นการเฉพาะ และโมดูล MicroPython 2 ตัวที่อยู่ใน archive โดย archive ตัวนี้ถูกลิงก์เฉพาะเมื่อ BENTO_HAS_MPY=1 เท่านั้น — บนเส้นทาง mtb-only โมดูลนี้ให้ symbol มา ศูนย์ตัว ยกเว้นชื่อ lfs_wifi_creds_* ทั้ง 6 ตัว ซึ่ง build ของ mtb-only จัดหามาให้ใหม่ในรูปซอร์สที่ส่งมอบจริง (storage_c/lfs_wifi_creds_c.c) จึงถูกกำกับไว้ด้านล่างว่าใช้ได้ทั้ง mtb-mpy และ mtb-only

ไม่มีไฟล์ implementation ของโมดูลนี้ส่งมอบมาในเทมเพลตเลย มีเพียง header เท่านั้น ตัวอย่างทุกชิ้นบนหน้าเหล่านี้เป็นโค้ดจริงของผู้ใช้ไลบรารีที่ส่งมอบมา (ไฟล์ .c ใต้ template/bento_libs/claw/common/mpy ซึ่งยกมาด้วย \snippet) หรือไม่ก็เป็นตัวอย่างที่เขียนขึ้นเองซึ่งกำกับไว้ชัดเจนว่าไม่มี call site ในของที่ส่งมอบจริง ใน 46 ตัวอย่างนี้ มี 8 ตัวอย่างที่เขียนขึ้นเอง

symbol ที่ export ออกมา 4 ตัวไม่มีคำประกาศอยู่ใน header ของ mpy_secure ที่ส่งมอบมาเลย (bento_secure_undeclared.h บันทึกไว้ทีละตัว) ได้แก่ mp_module_optiga และ mp_module_edge_ai (การลงทะเบียนโมดูล), bento_link_ipc_query (bento_link_ipc_query) และ optiga_verify_staged_model (การตรวจสอบด้วย OPTIGA — เป็น WEAK; prototype ของมันส่งมอบมาในโมดูล tesaiot_hsm) เมื่อไม่มีคำประกาศให้เอกสาร \fn ผูกเข้าด้วย ทั้ง 4 ตัวจึงถูกบันทึกไว้ในรูปหมายเหตุ ไม่ใช่รายการฟังก์ชัน — เป็นกฎเดียวกับที่โมดูล Edge AI ใช้กับ link hazard ของ printf/puts
