Detailed Description

8 ฟังก์ชัน: hash ของเฟิร์มแวร์ (fw_hash_*) และกระบวนการอัปเดต (bento_fw_*) คอมไพล์เฉพาะเมื่อ ENABLE_PAGE_BENTO_BUDDY=1 (ค่าตั้งต้นคือ 0, proj_cm33_ns/Makefile:64, :305) ให้ build ใหม่หลังจาก make getlibs — ดู Flag gate (อ่านก่อน)

การประกาศ: fw_hash.h และ bento_fw.h (ซึ่งประกาศ jsmntok_t ล่วงหน้าไว้เอง จึงไม่ต้องใช้ vendor/jsmn.h) ส่วนการนำไปสร้างจริงใน fw_hash.c / bento_fw.c ถูกเก็บไว้ใน libbento_secure.a การแฟลชทุกครั้งที่สั่งมาจากฝั่ง desktop ต้องผ่านคำถามยืนยัน Y/N บนจอ LCD ของอุปกรณ์ ซึ่งแสดงอักขระ hex 8 ตัวแรกของ SHA-256 ปลายทาง ไม่มีทางลัดข้าม และไม่มีการตอบ yes ให้เองเมื่อหมดเวลา

variant ที่ใช้ได้
mtb-mpy และ mtb-only

ข้อกำหนดการเรียกใช้
เขียน hex 8 อักขระแรก + NUL ลงใน out9 ซึ่ง ต้องมีอย่างน้อย 9 ไบต์ (ชื่อพารามิเตอร์คือข้อกำหนดนั้นเอง) ก่อนที่ digest จะถูกคำนวณ ค่านำหน้าที่ได้คือค่านำหน้าของ "unknown" ไม่มีผู้เรียกที่ใดเลย
variant ที่ใช้ได้
mtb-mpy และ mtb-only
ตัวอย่าง (เขียนขึ้นเอง — ไม่มี call site ในของที่ส่งมอบจริง)
__attribute__((used))
static void bento_ex_fw_hash_prefix8(void)
{
fw_hash_compute_at_boot(); /* idempotent — cache the digest */
char prefix[9]; /* contract: >= 9 bytes */
fw_hash_prefix8(prefix);
/* prefix now holds e.g. "3fa9c21b" — show it on the physical-ack
* prompt so the operator can match it against the desktop's hash. */
(void)prefix;
}
