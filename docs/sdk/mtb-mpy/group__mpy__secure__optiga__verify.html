optiga_verify_staged_model
int optiga_verify_staged_model(const uint8_t *blob, uint32_t blob_len)

Contract. Verifies the signature over a staged model region before it is handed to the model registry. Return 1 means the signature is good; negative codes are distinct on purpose — no signature, malformed, rejected by the chip, and could-not-ask-the-chip call for different responses and must never be collapsed into one "failed". Record the return on every path, including success. Talks to the secure element: task context only, never an ISR; the OPTIGA manager must be up, and the strong definition holds CM55 touch off the shared SCB5 bus for the whole transaction. Zero template call sites: the only caller anywhere is in the archived modedgeai.c model-staging path, which is not shipped as source.

Checked, but not yet enforced.** In a default build the check really runs and really produces a verdict — the strong definition is present in the CM33_NS ELF as optiga_verify_staged_model (arm-none-eabi-nm on proj_cm33_ns/build/KIT_PSE84_AI/Release/proj_cm33_ns.elf, 2026-08-29; absent from CM33_S and CM55). That verdict is recorded, not acted on.

The archived caller raises only under EDGE_AI_REQUIRE_SIGNED == 1, and that macro is defined nowhere in this package; none of its three refusal strings appears in any core ELF. So an unsigned model, or one whose signature is bad, is still staged and still loaded** — the result surfaces only as stage_info()['sig_rc'] and stage_info()['signed'].

A consumer who wants enforcement must read those two fields and refuse, in the shape the example below uses, or build with EDGE_AI_REQUIRE_SIGNED=1. Making that the default, and surfacing the flag as a Makefile setting, is open work.

Example (authored — no shipped call site)
/* Hand-written extern — mpy_secure ships no declaration for this symbol.
* Prototype copied from optiga_trust_helpers.h:179. */
extern int optiga_verify_staged_model(const uint8_t *blob, uint32_t blob_len);
static int32_t s_stage_sig_rc; /* last verify rc — kept ALWAYS */
static bool s_stage_signed;
__attribute__((used))
static void bento_ex_optiga_verify_staged_model(void)
{
const uint8_t *staged_base = (const uint8_t *)0x60800000u; /* staging */
uint32_t staged_total = 4096u; /* bytes */
const int sv = optiga_verify_staged_model(staged_base, staged_total);
/* Record the rc always, including on success — two fields about two
* different uploads must never be read as one. */
s_stage_sig_rc = sv;
s_stage_signed = (sv == 1);
if (!s_stage_signed) {
/* Refuse to register the model. Surface sv verbatim: a bus
* failure must not be reported as an attack. */
return;
}
/* Only now hand the region to the model registry. */
}
