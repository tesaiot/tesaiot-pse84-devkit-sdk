Detailed Description

Four functions: an HTTPS POST client to the TESAIoT APISIX gateway over cy_http_client and TLS. Implemented in claw_transport.c, compiled into libbento_mpy.a, not shipped as source. All four are called from template/bento_libs/claw/common/mpy/modbentoclaw.c in MicroPython task context; the transport carries no lock of its own.

The order that the shipped code enforces, and that this family documents function by function: claw_ipc_init() → claw_trust_set(CLAW_TRUST_HTTPS) → claw_https_connect() (trust reverted on failure) → claw_https_connected() guard → claw_cb_allow() → claw_https_post() → claw_cb_success() / claw_cb_failure() → claw_https_disconnect() followed by claw_trust_set(CLAW_TRUST_USB).

Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)

◆ claw_https_connected()

bool claw_https_connected ( void )

Connection-state predicate; checked before the circuit breaker, cheap and safe anytime.

Contract
Connection-state predicate: cheap, non-blocking, and safe to call before claw_https_connect() has ever run (it simply returns false). bentoclaw_ensure_init() precedes it at every one of its seven shipped sites. Ordering is load-bearing: connectivity is checked before the circuit breaker, so a "not connected" error is never misreported as a tripped breaker. Also used in the status dictionaries and the TACP STATUS reply. No locking; MicroPython task context.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The guard at the head of bentoclaw.ask().
static mp_obj_t bentoclaw_ask(mp_obj_t prompt_obj) {
bentoclaw_ensure_init();
if (!claw_https_connected()) {
mp_raise_msg(&mp_type_RuntimeError,
MP_ERROR_TEXT("not connected — call bentoclaw.connect() first"));
}
if (!claw_cb_allow()) {
mp_raise_msg(&mp_type_RuntimeError,
MP_ERROR_TEXT("circuit breaker open"));
}

◆ claw_https_connect()

bool claw_https_connect ( const char * host,
uint16_t port,
const char * api_key )

Open the TLS connection and store the API key; trust raised before, reverted on failure.

Contract
Opens the TLS connection to host:port and stores the device API key for the gateway's key-auth plugin. Returns true on success. claw_ipc_init() runs before the call so the status text can reach the CM55 panel. Trust is raised to CLAW_TRUST_HTTPS before the attempt and reverted to CLAW_TRUST_USB inside the else on failure — that pairing is the contract, not an option (see claw_trust_set()). Success appends a CLAW_ROLE_SYSTEM turn to the session. Blocking for the duration of the TLS handshake; MicroPython task context; no locking.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
Inside bentoclaw_connect().
/* ...context: inside bentoclaw_connect() ... */
claw_ipc_init();
claw_ipc_send_ui(CLAW_UI_STATUS_TEXT, "Connecting...", 13);
claw_trust_set(CLAW_TRUST_HTTPS);
bool ok = claw_https_connect(host, port, api_key);
if (ok) {
claw_ipc_send_ui(CLAW_UI_STATUS_TEXT, "Online (HTTPS)", 14);
claw_session_add(CLAW_ROLE_SYSTEM, "Connected to TESAIoT backend");
} else {
claw_ipc_send_ui(CLAW_UI_STATUS_TEXT, "Connect failed", 14);
claw_trust_set(CLAW_TRUST_USB);
}

◆ claw_https_post()

int claw_https_post ( const char * path,
const char * json,
size_t json_len,
char * resp_buf,
size_t resp_max )

POST json to path; returns response bytes written, negative on failure.

Contract
POSTs json_len bytes of json to path and writes the response body into resp_buf. Returns the number of response bytes written, or negative on failure — test resp_len < 0. The two shipped sites differ (rlen > 0 in the TACP path treats an empty body as failure); the negative check shown here is the correct pattern. claw_https_connected() must be true first. The response buffer must not alias the request buffer: the shipped code builds the request in s_work_large and receives into s_work_small — the comment "response overwrites s_work_small" makes the constraint explicit. json_len is the snprintf return, never strlen of a possibly truncated buffer. Blocking; MicroPython task context; no locking. Pair every call with claw_cb_failure() (before the raise) or claw_cb_success().
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
Request assembly, the POST, and the negative-return branch.
/* ...context: inside bentoclaw_ask() ... */
/* 4) Build JSON in s_work_large (no overlap with s_work_small) */
int json_len = snprintf(s_work_large, sizeof(s_work_large),
"{\"prompt\":\"%.*s\",\"context\":\"%.*s\"}",
(int)ep_len, esc_p, (int)ec_len, esc_c);
/* 5) POST to backend — response overwrites s_work_small */
int resp_len = claw_https_post("/ai/v1/chat", s_work_large, (size_t)json_len,
s_work_small, sizeof(s_work_small));
/* ...context: inside bentoclaw_ask(), after claw_https_post() ... */
if (resp_len < 0) {
s_agent_state = CLAW_STATE_ERROR;
s_error_count++;
claw_cb_failure();
claw_ipc_send_ui(CLAW_UI_ERROR, "Backend error", 13);
snprintf(s_last_result, sizeof(s_last_result), "error");
claw_ipc_send_ui(CLAW_UI_LAST_RESULT, s_last_result, strlen(s_last_result));
mp_raise_msg(&mp_type_RuntimeError, MP_ERROR_TEXT("HTTPS request failed"));
}

◆ claw_https_disconnect()

void claw_https_disconnect ( void )

Close the connection; must be followed by claw_trust_set(CLAW_TRUST_USB).

Contract
Closes the connection. Unconditional and without an init guard — the shipped binding does not call bentoclaw_ensure_init() and calling it while disconnected is harmless. It must be followed by claw_trust_set(CLAW_TRUST_USB): the transport does not touch the trust level itself, and leaving CLAW_TRUST_HTTPS set after the link is gone misdescribes the transport the next tool call arrives on. The CM55 status update is guarded on claw_ipc_initialized. Void; MicroPython task context; no locking.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
bentoclaw_disconnect(), with the trust revert.
static mp_obj_t bentoclaw_disconnect(void) {
claw_https_disconnect();
claw_trust_set(CLAW_TRUST_USB);
if (claw_ipc_initialized) {
claw_ipc_send_ui(CLAW_UI_STATUS_TEXT, "Offline", 7);
}
claw_session_add(CLAW_ROLE_SYSTEM, "Disconnected from backend");
return mp_const_none;
}
