Module registrations
MicroPython Agent (BentoClaw) » MicroPython Secure (libbento_mpy.a)

Two exported data symbols, not functions: the MicroPython module objects for optiga and edge_ai. Both are defined only inside the archive (modoptiga.c and modedgeai.c, compiled into libbento_mpy.a, not shipped as source), and bento_secure_undeclared.h records that no declaration exists anywhere in the tree. The only template usage is the registration block in template/bento_libs/claw/common/mpy/bento_archived_qstrs.c.

Consumers do not call or reference these symbols directly. They are consumed by MP_REGISTER_MODULE, and the surrounding comment is the contract: the qstr / root-pointer block is copied byte for byte from the generated headers, not re-derived from the sources — root_pointers.h sorts by the full declaration string, so a changed space moves a struct offset and the archived module objects would then be laid out against the wrong pool.

Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)

mp_module_optiga

/* No shipped declaration. Archived definition (modoptiga.c):
* const mp_obj_module_t mp_module_optiga;
* Consumed only through MP_REGISTER_MODULE(MP_QSTR_optiga, mp_module_optiga). */

Contract. The optiga module object (the OPTIGA Trust M surface exposed to Python). Never referenced by consumer code; the registration macro is the only legitimate use, and it must sit inside the byte-for-byte copied qstr block so the module's qstr indices match the pool the archive was compiled against — the _Static_assert lines above the block are what fail the build if the pool moves. bento_secure_undeclared.h records that no declaration exists in the tree; do not write one.

Example — the registration block.

/* Copied byte for byte from genhdr/module and genhdr/root_pointer.
* Not re-derived from the sources: root_pointers.h sorts by the full
* declaration string, so a changed space moves a struct offset. */
MP_REGISTER_MODULE(MP_QSTR_optiga, mp_module_optiga);
MP_REGISTER_MODULE(MP_QSTR_edge_ai, mp_module_edge_ai);

mp_module_edge_ai

/* No shipped declaration. Archived definition (modedgeai.c):
* const mp_obj_module_t mp_module_edge_ai;
* Consumed only through MP_REGISTER_MODULE(MP_QSTR_edge_ai, mp_module_edge_ai). */

Contract. The edge_ai module object. Same caveats as mp_module_optiga: registration only, inside the byte-for-byte copied block; never re-derive the qstr / root-pointer block from sources; no declaration exists in the tree.
