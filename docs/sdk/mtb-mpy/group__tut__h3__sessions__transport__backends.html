H3 — Sessions, transport, and backends
MicroPython Agent (BentoClaw) » Tutorials
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)

Excluded from the mtb-only documentation set.

Learning goal

Build a request context from the session with the caller-owned-buffer discipline, run the HTTPS connect → post → disconnect trio with the correct checks, and bring up a bento_link backend in the required order. Verify with an ask() round trip.

Real firmware sequence

Session add. NUL-terminated content; roles seen in shipped code are USER, ASSISTANT, SYSTEM and TOOL; the assistant turn is appended only after claw_cb_success():

/* ...context: inside bentoclaw_ask() ... */
/* Add user message to session */
claw_session_add(CLAW_ROLE_USER, prompt);
/* ...context: inside bentoclaw_ask(), success path ... */
s_agent_state = CLAW_STATE_IDLE;
claw_cb_success();
snprintf(s_last_result, sizeof(s_last_result), "ok (%d bytes)", resp_len);
claw_ipc_send_ui(CLAW_UI_LAST_RESULT, s_last_result, strlen(s_last_result));
claw_ipc_send_ui(CLAW_UI_STATUS_TEXT, "Online (HTTPS)", 14);
/* Add assistant response to session (s_work_small holds response) */
claw_session_add(CLAW_ROLE_ASSISTANT, s_work_small);
return mp_obj_new_str(s_work_small, (size_t)resp_len);

Context build. The caller supplies the buffer (s_work_large[3072] / s_work_small[512], modbentoclaw.c:237-238) with a deliberate 256-byte headroom; the result is not JSON-escaped and must pass through json_escape before entering a request body; buffers never overlap:

/* ...context: inside bentoclaw_ask() ... */
/* Build context → escape both → build JSON → POST.
* Escape prompt+context into s_work_small halves, then build JSON
* in s_work_large (no overlap). */
/* 1) Build context string in s_work_large */
size_t ctx_len = claw_session_build_context(s_work_large, sizeof(s_work_large) - 256);
/* 2) Escape prompt into s_work_small first half */
char *esc_p = s_work_small;
size_t ep_max = sizeof(s_work_small) / 2;
size_t ep_len = json_escape(esc_p, ep_max, prompt,
prompt_len > 200 ? 200 : prompt_len);
/* 3) Escape context into s_work_small second half */
char *esc_c = s_work_small + ep_max;
size_t ec_max = sizeof(s_work_small) / 2;
size_t ec_len = json_escape(esc_c, ec_max,
s_work_large, ctx_len > 200 ? 200 : ctx_len);
/* ...context: inside bentoclaw_ask() ... */
/* 4) Build JSON in s_work_large (no overlap with s_work_small) */
int json_len = snprintf(s_work_large, sizeof(s_work_large),
"{\"prompt\":\"%.*s\",\"context\":\"%.*s\"}",
(int)ep_len, esc_p, (int)ec_len, esc_c);

Transport trio. Connectivity is checked before the circuit breaker at every ask site:

static mp_obj_t bentoclaw_ask(mp_obj_t prompt_obj) {
bentoclaw_ensure_init();
if (!claw_https_connected()) {
mp_raise_msg(&mp_type_RuntimeError,
MP_ERROR_TEXT("not connected — call bentoclaw.connect() first"));
}
if (!claw_cb_allow()) {
mp_raise_msg(&mp_type_RuntimeError,
MP_ERROR_TEXT("circuit breaker open"));
}

claw_https_post() returns bytes written to resp or negative on failure; the response buffer must not alias the request buffer:

/* ...context: inside bentoclaw_ask() ... */
/* 4) Build JSON in s_work_large (no overlap with s_work_small) */
int json_len = snprintf(s_work_large, sizeof(s_work_large),
"{\"prompt\":\"%.*s\",\"context\":\"%.*s\"}",
(int)ep_len, esc_p, (int)ec_len, esc_c);
/* 5) POST to backend — response overwrites s_work_small */
int resp_len = claw_https_post("/ai/v1/chat", s_work_large, (size_t)json_len,
s_work_small, sizeof(s_work_small));
/* ...context: inside bentoclaw_ask(), after claw_https_post() ... */
if (resp_len < 0) {
s_agent_state = CLAW_STATE_ERROR;
s_error_count++;
claw_cb_failure();
claw_ipc_send_ui(CLAW_UI_ERROR, "Backend error", 13);
snprintf(s_last_result, sizeof(s_last_result), "error");
claw_ipc_send_ui(CLAW_UI_LAST_RESULT, s_last_result, strlen(s_last_result));
mp_raise_msg(&mp_type_RuntimeError, MP_ERROR_TEXT("HTTPS request failed"));
}

Connect and disconnect, with the trust pairing, are in H2 — The claw safety gates.

Session status and clear. claw_session_count() feeds the status dict; claw_session_clear() is paired with a UI clear:

/* ...context: inside bentoclaw_status() ... */
mp_obj_dict_store(MP_OBJ_FROM_PTR(d),
MP_OBJ_NEW_QSTR(MP_QSTR_session_msgs),
mp_obj_new_int(claw_session_count()));
static mp_obj_t bentoclaw_session_clear(void) {
bentoclaw_ensure_init();
claw_session_clear();
if (claw_ipc_initialized) {
claw_ipc_send_ui(CLAW_UI_CLEAR, "", 0);
}
return mp_const_none;
}

Backends. Required order: bento_link_ipc_init() → bento_link_get("ipc") → NULL-check → wire into the adapter:

static void ensure_inited(void)
{
if (s_inited) {
return;
}
if (!bento_link_ipc_init()) {
mp_raise_msg(&mp_type_OSError, MP_ERROR_TEXT("model link init failed"));
}
s_adapter.base.send = adapter_send;
s_adapter.base.register_receive_cb = adapter_register_receive;
s_adapter.link = bento_link_get("ipc");
if (s_adapter.link == NULL) {
mp_raise_msg(&mp_type_OSError, MP_ERROR_TEXT("ipc link unavailable"));
}
s_iface.IPC = &s_adapter.base;
model_type_t model = { .va_model = DEEPCRAFT_VA_MODEL };
deepcraft_engine_init(&s_engine, model, &s_iface);
deepcraft_engine_set_event_cb(&s_engine, engine_event_cb);

Iterate registered backends up to BENTO_LINK_MAX_BACKENDS, breaking on NULL:

static mp_obj_t deepcraft_links(void)
{
ensure_inited();
mp_obj_t items[BENTO_LINK_MAX_BACKENDS];
uint32_t n = 0;
for (uint32_t i = 0; i < BENTO_LINK_MAX_BACKENDS; i++) {
bento_link_t *l = bento_link_at(i);
if (l == NULL) {
break;
}
items[n++] = mp_obj_new_str(l->name, strlen(l->name));
}
return mp_obj_new_tuple(n, items);
}

Step by step

Step 1 — Round trip

>>> import bentoclaw
>>> bentoclaw.ask("What is on the display?")

What you should observe. A reply string, and bentoclaw.status()['session_msgs'] grows by two (user + assistant). The last-result string ok (d bytes) is pushed to the CM55 BentoClaw page (modbentoclaw.c:471-473). If the link is down: RuntimeError from the ask guard, before any breaker accounting.

Step 2 — Clear and confirm

>>> bentoclaw.session_clear()
>>> bentoclaw.status()['session_msgs']
0

What you should observe. Count 0 and the CM55 page's transcript cleared in the same call.

Step 3 — Inspect backends

>>> import deepcraft

What you should observe. Import succeeds only if bento_link_get("ipc") returned non-NULL at module init; the snippet above is the path that runs.

Authored (no shipped call site)

bento_link_ipc_query — 0 template calls; no declaration ships (bento_secure_undeclared.h:11), so the consumer hand-writes the extern. bento_link_register — backend-author API, modelled on the archived self-registration in bento_link_ipc.c:245. claw_session_flush, claw_session_dirty, claw_memory_get — zero callers anywhere. Their examples in the mpy_secure reference carry the authored label; nothing in this chapter depends on them.

Traps

Warning
rlen > 0 is the wrong test for claw_https_post() (the :2213 site differs from the correct negative check at :459); a zero-length success is legal.
Unescaped context in a JSON body breaks the request the first time a user types a quote.
bento_link_get before bento_link_ipc_init returns NULL — the init self-registers the backend.
