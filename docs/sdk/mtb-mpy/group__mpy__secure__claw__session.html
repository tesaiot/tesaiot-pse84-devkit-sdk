Detailed Description

Nine functions over two LittleFS files: /.bentoclaw_session, a JSONL ring buffer of the last CLAW_SESSION_MAX_MSGS (10) conversation turns, and /.bentoclaw_memory, a persistent key/value store that survives claw_session_clear(). The implementation, claw_session.c, is compiled into libbento_mpy.a and does not ship as source; it does its file I/O by executing Python open() through the MicroPython VFS bridge, which is why every function here requires MicroPython task context and why the subsystem has no locking at all — only the MicroPython task touches it.

claw_session_init() runs once from the idempotent bentoclaw_ensure_init() (see Claw safety gates); no other initialisation is exposed.

Six of the nine have shipped call sites in modbentoclaw.c. Three — claw_memory_get(), claw_session_dirty(), claw_session_flush() — have no caller anywhere, in the template or in the archived tree; their examples are authored and labelled as such.

Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)

◆ claw_session_init()

void claw_session_init ( void )

Initialise the session subsystem; called exactly once, via bentoclaw_ensure_init().

Contract
Initialises the session subsystem (in-RAM ring state; the files are touched lazily). Called exactly once, from the idempotent bentoclaw_ensure_init(), after claw_rate_init() and claw_cb_init(). MicroPython task context; void; no locking. No shipped code calls it from anywhere else — a second call would drop the in-RAM ring without flushing it.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The single shipped call site.
static void bentoclaw_ensure_init(void) {
if (s_module_inited) return;
claw_rate_init();
claw_cb_init();
claw_session_init();
/* Set per-tool rate limits from registry */
for (size_t i = 0; i < TOOL_COUNT; i++) {
if (s_tools[i].rate_per_min > 0) {
claw_rate_set(s_tools[i].name, s_tools[i].rate_per_min);
}
}
s_module_inited = true;
}

◆ claw_session_add()

bool claw_session_add ( claw_role_t role,
const char * content )

Append one message and trim the ring to CLAW_SESSION_MAX_MSGS.

Contract
Appends one message and trims the ring to CLAW_SESSION_MAX_MSGS; content must be NUL-terminated and is truncated to CLAW_MSG_MAX_LEN (256). claw_session_init() must have run (via bentoclaw_ensure_init()). Roles used by shipped code: CLAW_ROLE_USER, CLAW_ROLE_ASSISTANT, CLAW_ROLE_SYSTEM (on connect and disconnect) and CLAW_ROLE_TOOL (tool results). Ordering in the ask() path is deliberate: the user turn is added before the request is built, and the assistant turn is appended only after claw_cb_success() — a failed request leaves no assistant entry. The bool return is discarded at every shipped site. No locking — single MicroPython task.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The user turn, added before the request is built:
/* ...context: inside bentoclaw_ask() ... */
/* Add user message to session */
claw_session_add(CLAW_ROLE_USER, prompt);

The assistant turn, after the breaker has recorded success:

/* ...context: inside bentoclaw_ask(), success path ... */
s_agent_state = CLAW_STATE_IDLE;
claw_cb_success();
snprintf(s_last_result, sizeof(s_last_result), "ok (%d bytes)", resp_len);
claw_ipc_send_ui(CLAW_UI_LAST_RESULT, s_last_result, strlen(s_last_result));
claw_ipc_send_ui(CLAW_UI_STATUS_TEXT, "Online (HTTPS)", 14);
/* Add assistant response to session (s_work_small holds response) */
claw_session_add(CLAW_ROLE_ASSISTANT, s_work_small);
return mp_obj_new_str(s_work_small, (size_t)resp_len);

◆ claw_session_clear()

void claw_session_clear ( void )

Delete /.bentoclaw_session and empty the ring; the memory store is untouched.

Contract
Deletes /.bentoclaw_session and empties the ring; /.bentoclaw_memory is untouched. The shipped consumer pairs it with a CLAW_UI_CLEAR IPC message so the CM55 conversation panel is cleared in the same step — the guard on claw_ipc_initialized is what makes the pair safe before the IPC link is up. bentoclaw_ensure_init() first; void; MicroPython task context (deletes a file through the VFS bridge).
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The paired session/UI clear.
static mp_obj_t bentoclaw_session_clear(void) {
bentoclaw_ensure_init();
claw_session_clear();
if (claw_ipc_initialized) {
claw_ipc_send_ui(CLAW_UI_CLEAR, "", 0);
}
return mp_const_none;
}

◆ claw_session_build_context()

size_t claw_session_build_context ( char * out_buf,
size_t out_max )

Render recent turns plus memory into a caller-supplied buffer; not JSON-escaped.

Contract
Renders recent session turns plus persistent memory into a prompt-context string. The caller supplies the buffer — the shipped module's shared statics are s_work_large[3072] and s_work_small[512] — and the shipped call passes sizeof(s_work_large) - 256, a deliberate 256-byte headroom reservation. Returns bytes written. The result is not JSON-escaped: it must pass through json_escape before entering a request body, exactly as the exemplar does. The escape targets and the JSON assembly buffer never overlap (context in s_work_large, escaped halves in s_work_small, then JSON back into s_work_large after the context has been consumed). A simpler shipped form passes the full buffer size. claw_session_init() first; MicroPython task context; no locking.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
Build, escape, assemble, with the headroom and the non-overlapping buffer discipline.
/* ...context: inside bentoclaw_ask() ... */
/* Build context → escape both → build JSON → POST.
* Escape prompt+context into s_work_small halves, then build JSON
* in s_work_large (no overlap). */
/* 1) Build context string in s_work_large */
size_t ctx_len = claw_session_build_context(s_work_large, sizeof(s_work_large) - 256);
/* 2) Escape prompt into s_work_small first half */
char *esc_p = s_work_small;
size_t ep_max = sizeof(s_work_small) / 2;
size_t ep_len = json_escape(esc_p, ep_max, prompt,
prompt_len > 200 ? 200 : prompt_len);
/* 3) Escape context into s_work_small second half */
char *esc_c = s_work_small + ep_max;
size_t ec_max = sizeof(s_work_small) / 2;
size_t ec_len = json_escape(esc_c, ec_max,
s_work_large, ctx_len > 200 ? 200 : ctx_len);
/* ...context: inside bentoclaw_ask() ... */
/* 4) Build JSON in s_work_large (no overlap with s_work_small) */
int json_len = snprintf(s_work_large, sizeof(s_work_large),
"{\"prompt\":\"%.*s\",\"context\":\"%.*s\"}",
(int)ep_len, esc_p, (int)ec_len, esc_c);

◆ claw_memory_set()

bool claw_memory_set ( const char * key,
const char * value )

Store a persistent key/value pair that survives clear and soft reset.

Contract
Stores a persistent key/value pair in /.bentoclaw_memory; key at most CLAW_MEM_KEY_MAX (32) characters, value at most CLAW_MEM_VAL_MAX (128). Returns true on success, false when the store is full or unwritable — the TACP REMEMBER handler turns that bool directly into an "ok" / "full" reply. Part of the safety subsystem's persistent state alongside the trust/rate family: it survives claw_session_clear() and soft reset. bentoclaw_ensure_init() first; MicroPython task context; no locking.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The bentoclaw.remember() binding, the canonical exemplar.
static mp_obj_t bentoclaw_remember(mp_obj_t key_obj, mp_obj_t val_obj) {
bentoclaw_ensure_init();
const char *key = mp_obj_str_get_str(key_obj);
const char *val = mp_obj_str_get_str(val_obj);
bool ok = claw_memory_set(key, val);
return mp_obj_new_bool(ok);
}

bool claw_memory_get ( const char * key,
char * out_value,
size_t out_max )

Look a key up in /.bentoclaw_memory; false when absent. No shipped caller.

Contract
Looks up key in /.bentoclaw_memory and copies the value into out_value (size the buffer to CLAW_MEM_VAL_MAX). Returns true if found, false when absent or the store is unreadable — not an error worth raising over; fall back to a default. claw_session_init() must have run; MicroPython task context (reads a file through the VFS bridge); no locking. No shipped caller exists — not in the template and not in the archived tree; the definition (claw_session.c) is only reachable through the archive.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example (authored — no shipped call site)
__attribute__((used))
static void bento_ex_claw_memory_get(void)
{
char value[CLAW_MEM_VAL_MAX];
/* false = key absent (or store unreadable) — not an error path worth
* raising over; fall back to the default. */
if (!claw_memory_get("user_name", value, sizeof(value))) {
(void)strncpy(value, "friend", sizeof(value) - 1u);
value[sizeof(value) - 1u] = '\0';
}
(void)value;
}

Cheap predicate: unflushed changes in the in-RAM ring? No shipped caller.

Contract
Cheap predicate with no I/O: true when the in-RAM ring holds changes not yet flushed to flash. Intended for deciding whether a flush is worth doing at a quiet moment, mirroring the shipped wifi_creds_flush_if_dirty() idiom (lfs_wifi_creds_write()). MicroPython task context; no locking. No shipped caller exists anywhere.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example (authored — no shipped call site)
__attribute__((used))
static bool bento_ex_claw_session_dirty(void)
{
/* Nothing to do while clean — skip the flash write entirely. */
return claw_session_dirty();
}

◆ claw_session_flush()

bool claw_session_flush ( void )

Write the dirty ring to flash, from MicroPython task context only. No shipped caller.

Contract
Writes the dirty ring to /.bentoclaw_session on QSPI. Must be called from MicroPython task context (header contract — the write executes Python open()). Returns true on success; on failure the session stays dirty so a later call retries — never clear state around a failed flash write. A flash write takes milliseconds: call at idle points, not per message. No shipped caller exists anywhere.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example (authored — no shipped call site)
__attribute__((used))
static void bento_ex_claw_session_flush(void)
{
if (!claw_session_dirty()) {
return; /* nothing pending */
}
if (!claw_session_flush()) {
/* Failed write: the session stays dirty — the next idle-point
* call retries. Do not clear anything here. */
return;
}
}
