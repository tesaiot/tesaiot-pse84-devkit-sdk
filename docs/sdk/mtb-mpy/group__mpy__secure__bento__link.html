Detailed Description

Five symbols: the bento_link registry (bento_link_register(), bento_link_get(), bento_link_at()) and the shipped "ipc" backend's two entry points (bento_link_ipc_init(), bento_link_ipc_query). Implemented in bento_link.c and bento_link_ipc.c, compiled into libbento_mpy.a, not shipped as source. bento_link.h declares the three registry functions; bento_secure_undeclared.h carries the recovered bento_link_ipc_init() prototype and records that bento_link_ipc_query() has no declaration anywhere in the tree — the consumer hand-writes the extern.

The shipped exemplar is template/bento_libs/claw/common/mpy/moddeepcraft.c, and its required order is the contract: bento_link_ipc_init() → bento_link_get("ipc") → NULL-check → wire the returned bento_link_t into the DEEPCRAFT™ adapter.

Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)

◆ bento_link_ipc_init()

bool bento_link_ipc_init ( void )
extern

Bring up the IPC backend and self-register it as "ipc"; must precede bento_link_get().

Contract
Brings up the CM33-to-CM55 pipe backend and self-registers it in the link registry under the name "ipc" (internally it calls bento_link_register()). Idempotent. Must precede bento_link_get("ipc") — before it the lookup returns NULL. Returns false when the pipe endpoint is not up; the shipped binding raises OSError on false. Task context; the shipped caller is the MicroPython task's lazy ensure_inited(). The prototype is the one bento_secure_undeclared.h recovers — no other shipped header declares this function.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
Init, lookup, NULL-check, wire-in.
static void ensure_inited(void)
{
if (s_inited) {
return;
}
if (!bento_link_ipc_init()) {
mp_raise_msg(&mp_type_OSError, MP_ERROR_TEXT("model link init failed"));
}
s_adapter.base.send = adapter_send;
s_adapter.base.register_receive_cb = adapter_register_receive;
s_adapter.link = bento_link_get("ipc");
if (s_adapter.link == NULL) {
mp_raise_msg(&mp_type_OSError, MP_ERROR_TEXT("ipc link unavailable"));
}
s_iface.IPC = &s_adapter.base;
model_type_t model = { .va_model = DEEPCRAFT_VA_MODEL };
deepcraft_engine_init(&s_engine, model, &s_iface);
deepcraft_engine_set_event_cb(&s_engine, engine_event_cb);

bento_link_t * bento_link_get ( const char * name)

Look a backend up by name; NULL when absent — always NULL-check.

Look up a backend by name; NULL if not compiled in / not registered.

Contract
Looks a backend up by name ("ipc", "usb", "ble", "wifi"); returns NULL when that backend is not compiled in or not yet registered. Always NULL-check — availability follows the board persona and the init order. Required order: bento_link_ipc_init() → bento_link_get("ipc") → NULL-check → store the pointer in the adapter. No locking; task context.

◆ bento_link_at()

bento_link_t * bento_link_at ( uint32_t index)

Enumerate the registry; NULL past the end.

Enumerate registered backends: index 0..n-1, NULL past the end.

Contract
Enumerates the registry: index 0 to n-1 returns a backend, NULL past the end. Iterate 0 to BENTO_LINK_MAX_BACKENDS and break on the first NULL — the registry is packed, so NULL means "no more". Backing store for Python's deepcraft.links(). No locking; task context.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
deepcraft_links().
static mp_obj_t deepcraft_links(void)
{
ensure_inited();
mp_obj_t items[BENTO_LINK_MAX_BACKENDS];
uint32_t n = 0;
for (uint32_t i = 0; i < BENTO_LINK_MAX_BACKENDS; i++) {
bento_link_t *l = bento_link_at(i);
if (l == NULL) {
break;
}
items[n++] = mp_obj_new_str(l->name, strlen(l->name));
}
return mp_obj_new_tuple(n, items);
}

◆ bento_link_register()

bool bento_link_register ( bento_link_t * link)

Backend-author API: register a transport's bento_link_t exactly once.

Register a backend (called once from each backend's init).

Contract
Backend-author API, not application API. A transport backend registers its own bento_link_t base exactly once, from its own init, before any consumer can bento_link_get() it — the shipped model is the "ipc" backend self-registering inside bento_link_ipc_init(). The registry holds at most BENTO_LINK_MAX_BACKENDS (4) entries; false means full or duplicate, and the backend must then report itself unavailable, not retry. Receive callbacks registered through the base must be delivered off interrupt context (ISR → queue → delivery task), per bento_link.h. No shipped call site exists in the template; the sole caller is inside the archive.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example (authored — no shipped call site)
static bool my_backend_send_ctrl(bento_link_t *self, uint8_t cmd,
uint32_t value)
{
(void)self; (void)cmd; (void)value;
return false; /* transport busy/unavailable */
}
static bool my_backend_send_data(bento_link_t *self, uint8_t stream_id,
const void *buf, uint16_t len)
{
(void)self; (void)stream_id; (void)buf; (void)len;
return false; /* v1: data plane reserved */
}
static void my_backend_register_receive(bento_link_t *self,
void (*ctrl_cb)(uint8_t cmd, uint32_t value),
void (*data_cb)(uint8_t stream_id, const void *buf,
uint16_t len, uint16_t seq))
{
(void)self; (void)ctrl_cb; (void)data_cb;
/* Backends MUST deliver callbacks OFF interrupt context
* (ISR -> queue -> delivery task), per bento_link.h. */
}
static bento_link_t s_my_backend = {
.send_ctrl = my_backend_send_ctrl,
.send_data = my_backend_send_data,
.register_receive = my_backend_register_receive,
.name = "wifi", /* the name consumers pass to _get() */
.mtu = 512u,
.bandwidth_bps = 100000u, /* honest sustained budget */
.flags = BL_F_LOSSY,
};
__attribute__((used))
static void bento_ex_bento_link_register(void)
{
/* Called once from the backend's own init. False = registry full
* (BENTO_LINK_MAX_BACKENDS) or duplicate — the backend must report
* itself unavailable, not retry. */
if (!bento_link_register(&s_my_backend)) {
return;
}
}
