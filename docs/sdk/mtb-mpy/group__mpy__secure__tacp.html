Detailed Description

Six functions: the UART-side control protocol the BENTO IDE speaks to the board (magic 0xAA 0x55, control commands, binary file transfer, and the BentoClaw 0x30 sub-protocol). Implemented in tacp.c, compiled into libbento_mpy.a, not shipped as source. The template ships tacp.h.

Four have shipped call sites (in mpy_main.c, modui.c, modsensors.c, modbentoclaw.c and sensor_auto_task.c). Two — tacp_ring_buf_read() and tacp_ring_buf_readable() — have no caller anywhere: in shipped firmware the MicroPython REPL consumes the ring internally. Their examples are authored and labelled.

Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)

◆ tacp_init()

void tacp_init ( void )

Reset the state machine, clear the ring, drain the FIFO; once per soft reset.

Initialize TACP state machine and ring buffer.

Contract
Resets the TACP state machine, clears the ring buffer and drains the UART FIFO. Called once per soft reset, at the soft_reset label of the MicroPython task, so stale bytes from before the reset cannot be re-parsed and cause a double reset. It must precede every other TACP function in this family — tacp_poll_uart() during init is only safe because tacp_init() has already run. MicroPython task context; void.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The soft-reset label in mpy_main.c.
/* ...context: inside the MicroPython task, at the soft_reset label ... */
soft_reset:
/* Clear TACP ring buffer, state machine, and UART FIFO on every
* soft reset so stale bytes don't cause double-resets. */
tacp_init();
/* Peek at safe-boot flag early so g_is_safe_boot is correct before
* check_boot_mode() runs later. Defensive: if any code path calls
* tacp_poll_uart() during init, the TACP handler sees the right value.
* The flag is NOT consumed here — check_boot_mode() handles that. */
g_is_safe_boot = (s_safe_boot_once_flag == MPY_SAFE_BOOT_MAGIC);

◆ tacp_poll_uart()

bool tacp_poll_uart ( void )

Pump the UART; must be called from every blocking wait loop.

Poll UART for TACP commands and REPL bytes. Returns true if a command was detected.

Contract
Pumps the UART: consumes available bytes, runs the TACP state machine, and pushes REPL bytes into the ring. It must be called from every blocking wait loop in MicroPython task context, otherwise Ctrl-C, the IDE Stop button and file uploads are dead for the duration of the wait. tacp_init() must have run, once per soft reset. The return value is deliberately discarded at all seven shipped sites — it is a pump, not a predicate. The canonical form pairs it with MICROPY_EVENT_POLL_HOOK; the FreeRTOS form pairs it with vTaskDelay(pdMS_TO_TICKS(1)) instead. No locking. Not ISR-safe — see tacp_request_delete_main_from_isr() for the one escape hatch when a runaway script starves this pump.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The canonical pump inside a UI IPC wait (modui.c):
/* ...context: inside the UI IPC response wait loop ... */
mp_uint_t deadline = mp_hal_ticks_ms() + timeout_ms;
while (!ui_ipc_resp.ready) {
if ((mp_int_t)(mp_hal_ticks_ms() - deadline) >= 0) break;
tacp_poll_uart();
MICROPY_EVENT_POLL_HOOK;
}

The FreeRTOS-yield variant (modsensors.c):

/* ...context: inside the joystick IPC response wait ... */
for (int w = 0; w < 50 && !js_ipc_response.ready; w++) {
tacp_poll_uart();
vTaskDelay(pdMS_TO_TICKS(1));

◆ tacp_request_delete_main_from_isr()

void tacp_request_delete_main_from_isr ( void )

ISR-safe escape hatch: break the script, soft-reset, remove /main.py.

ISR-safe trigger for the CM55 "Delete main.py" button. Breaks a running / looping script (keyboard interrupt) and forces a MicroPython soft reset so the boot path removes /main.py. Safe to call from interrupt context.

Contract
ISR-safe: breaks a running script (keyboard interrupt) and forces a MicroPython soft reset so the boot path removes /main.py. No allocation, no hard reset; SRAM flags survive the soft reset. It is the fallback for when a runaway /main.py loop monopolises the CPU and starves tacp_poll_uart() — the graceful path (s_delete_pending, polled in task context) still exists beside it. Called from the sensor-control IPC ISR on CM33_NS, guarded by BENTO_HAS_MPY: under the mtb-only variant there is no VM and no /main.py to delete, so the guard compiles the call out. Void.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The IPC ISR callback in sensor_auto_task.c.
/* ...context: inside the sensor-ctrl IPC ISR callback ... */
if (msg->cmd == IPC_CMD_DELETE_MAIN_PY) {
/* Graceful path: polled by tacp_poll_uart() in task context (works when
* the MP loop is alive, e.g. at the REPL). */
s_delete_pending = true;
/* Robust path: break the script + force a MicroPython soft reset DIRECTLY
* from this IPC ISR, so the Delete button works even when a runaway
* /main.py loop monopolises the CPU and starves tacp_poll_uart(). The
* soft reset keeps SRAM (s_delete_main_flag) intact -> boot removes
* /main.py. ISR-safe (no allocation, no hard reset). Ported from
* Game-libraries 8a0689a (HW-verified on Eva). */
#if BENTO_HAS_MPY
tacp_request_delete_main_from_isr();
#endif /* no VM: there is no /main.py to delete */

void tacp_claw_respond ( uint8_t sub_cmd,
const char * payload,
uint16_t payload_len )

Emit one BentoClaw binary response frame on the UART.

Send a BentoClaw TACP binary response frame. Frame: [0xAA][0x55][0x30][sub_cmd][len_lo][len_hi][payload][crc_lo][crc_hi] Use sub_cmd matching request for success, TACP_CLAW_ERROR (0xFF) for errors.

Contract
Emits one BentoClaw binary response frame on the UART (0xAA 0x55 0x30, sub-command, length, payload, CRC-16/CCITT). Use the request's sub_cmd for success and TACP_CLAW_ERROR (0xFF) for errors. tacp_init() first. payload_len is the actual length — the snprintf return cast to uint16_t — never strlen of a buffer that may have been truncated. Shipped code never calls it bare: it goes through the claw_respond / claw_respond_err wrappers. The unsolicited TACP_CLAW_READY frame is sent only after tacp_init(), mp_init(), the VFS mount and boot.py / main.py have completed, so the IDE never sees a READY from a board that cannot yet serve a request. Void, no error path; MicroPython task context. The archive's 20 internal responders in tacp.c are not consumer surface — the shipped consumer surface is exactly the three sites in modbentoclaw.c.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example
The wrappers and the READY frame.
static void claw_respond(uint8_t sub_cmd, const char *payload, uint16_t payload_len) {
tacp_claw_respond(sub_cmd, payload, payload_len);
}
static void claw_respond_err(const char *msg, uint16_t msg_len) {
tacp_claw_respond(TACP_CLAW_ERROR, msg, msg_len);
}
/*******************************************************************************
* READY frame — sent once at boot to announce firmware readiness.
* IDE listens for this instead of polling STATUS with delay+retry.
******************************************************************************/
void bentoclaw_send_ready(void) {
bentoclaw_ensure_init();
claw_ipc_init();
int n = snprintf(s_work_small, sizeof(s_work_small),
"{\"fw\":\"%s\",\"board\":\"%s\",\"tools\":%u,\"proto\":2}",
BENTOCLAW_VERSION, MICROPY_HW_BOARD_NAME, (unsigned)TOOL_COUNT);
tacp_claw_respond(TACP_CLAW_READY, s_work_small, (uint16_t)n);
/* Push initial stats to CM55 LCD so it shows real tool count immediately */
claw_ipc_send_stats();

◆ tacp_ring_buf_read()

int tacp_ring_buf_read ( void )

Pop one REPL byte, or -1 when empty. No shipped caller.

Read one byte from the ring buffer (for REPL consumption). Returns -1 if empty.

Contract
Pops one REPL byte (0 to 255) from the ring, or returns -1 when empty. The ring only fills while tacp_poll_uart() runs — pump first. tacp_init() once per soft reset; MicroPython task context; single consumer. No shipped caller exists — in shipped firmware the REPL consumes the ring inside the archive; the definition (tacp.c) is not shipped as source.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example (authored — no shipped call site)
__attribute__((used))
static void bento_ex_tacp_ring_buf_read(void)
{
/* Pump first — the ring only fills while tacp_poll_uart() runs.
* The return value is deliberately discarded at all shipped pump
* sites: it is a pump, not a predicate. */
(void)tacp_poll_uart();
int c;
while ((c = tacp_ring_buf_read()) >= 0) {
/* consume the byte (REPL character, 0..255) */
(void)c;
}
/* c == -1: ring empty — return to the wait loop and keep pumping. */
}

bool tacp_ring_buf_readable ( void )

Non-blocking data-available test. No shipped caller.

Check if the ring buffer has data.

Contract
Non-blocking data-available test: a volatile head/tail compare, safe to poll tightly. For callers that must not touch the ring speculatively; tacp_ring_buf_read() already reports emptiness as -1. tacp_init() first; MicroPython task context. No shipped caller exists anywhere.
Variant
mtb-mpy only (libbento_mpy.a is not linked under BENTO_HAS_MPY=0)
Example (authored — no shipped call site)
__attribute__((used))
static void bento_ex_tacp_ring_buf_readable(void)
{
(void)tacp_poll_uart(); /* keep the producer pumped */
if (!tacp_ring_buf_readable()) {
return; /* nothing buffered — no work */
}
int c = tacp_ring_buf_read(); /* guaranteed >= 0 right after a
* true readable() in this
* single-consumer context */
(void)c;
}
