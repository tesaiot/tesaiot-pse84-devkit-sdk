การเชื่อมต่อ: WiFi และคลาวด์

Tutorial หมวดการเชื่อมต่ออธิบาย API ที่ถูกจัดวางไว้ในโมดูลของส่วนอื่น เพราะไม่มีโมดูลการเชื่อมต่ออยู่จริง จึงไม่มีการย้ายโมดูลใดมาไว้ที่นี่ (API ของบทหมวด C อยู่ใน cm55_core, ที่เก็บข้อมูลรับรอง, ble_nus และซอร์สของเทมเพลตที่ส่งมอบมา)

  • wifi_saved_* — รายชื่อเครือข่ายที่บันทึกไว้ฝั่ง CM55 ซึ่งวางอยู่บนที่เก็บของ OPTIGA อธิบายไว้ที่ C2 — WiFi จาก UI ผ่าน IPC — จัดวางไว้กับคู่มืออ้างอิง CM55 Core ที่ เครือข่าย WiFi ที่บันทึกไว้ (ที่เก็บ OPTIGA)
  • lfs_wifi_creds_* — ที่เก็บข้อมูลรับรองสำหรับบูตบน LittleFS อธิบายไว้ที่ C1 — WiFi: ที่เก็บข้อมูลรับรอง 2 แห่งกับการเชื่อมต่ออัตโนมัติตอนบูต — จัดวางไว้กับส่วนที่เก็บข้อมูลและข้อมูลรับรองที่ ที่เก็บข้อมูลรับรอง WiFi (ที่อยู่เดียวกันในเว็บไซต์ของทั้งสอง variant)
  • lfs_load_wifi_creds / lfs_save_wifi_creds / app_wifi_* — โค้ดเชื่อม WiFi ฝั่ง C ที่เขียนทับได้ จัดวางไว้กับคู่มืออ้างอิง BLE NUS ที่ WiFi overridables (นิยามเอง ห้ามเรียก)
  • MQTT และ mTLS — ไม่ได้เป็นโมดูลที่คอมไพล์มาแล้วเลย ไปป์ไลน์นี้ส่งมอบมาในรูปซอร์สของเทมเพลต (tesaiot_mqtt/ — mqtt_task.c, mqtt_client_config.c, subscriber_task.c, publisher_task.c, mqtt_mtls_setup.c) และถูกยกมาโดยตรงในบท C3 — TESAIoT cloud: ไฟล์ config → MQTT task → broker และ C4 — mTLS: ตัวตนของ TLS ที่ยึดกับ OPTIGA
