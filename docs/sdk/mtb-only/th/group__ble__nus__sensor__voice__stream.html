Detailed Description

9 ฟังก์ชัน: sensor_stream_* และ voice_capture_* คอมไพล์เฉพาะเมื่อ ENABLE_PAGE_BENTO_BUDDY=1 (ค่าตั้งต้นคือ 0, proj_cm33_ns/Makefile:64, :305) ให้ build ใหม่หลังจาก make getlibs — ดู Flag gate (อ่านก่อน)

การประกาศ: sensor_stream.h, voice_capture.h ส่วนการนำไปสร้างจริงใน sensor_stream.c / voice_capture.c ถูกเก็บไว้ใน libbento_secure.a voice_capture เป็น stub ตามที่ header ของมันระบุไว้เอง: เส้นทาง PDM-PCM ตัวจริงยังไม่ได้ต่อ มันส่งความเงียบสังเคราะห์หนึ่งวินาทีออกมาเป็นเฟรม bento.voice.chunk เพื่อให้ตรวจสอบตัวแจงข้อมูลฝั่ง desktop ได้ตั้งแต่ต้นจนจบ
