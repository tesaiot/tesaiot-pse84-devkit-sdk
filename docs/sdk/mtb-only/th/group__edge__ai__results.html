Detailed Description

ฟังก์ชัน 6 ตัว: ตัวอ่านผลลัพธ์ 2 ตัว (พร้อมเงื่อนไขว่าแต่ละตัวใช้ได้เมื่อใด) คู่ฟังก์ชันไล่รายการใน registry และค่าอ่านการ settle 2 ค่าที่ parallel set เปิดให้ใช้

variant ที่ใช้ได้
mtb-mpy และ mtb-only

◆ ai_engine_snapshot_model()

bool ai_engine_snapshot_model ( uint32_t index,
ai_result_t * out )

ผลตัดสินล่าสุดของโมเดลหนึ่งตัว — เป็นตัวอ่านที่ต้องใช้ภายใน parallel set

One model's last verdict. Use this, not ai_engine_snapshot(), whenever several models may be publishing: that one reports whoever wrote most recently, so three quiet models can bury a detection before it is read. False if that model has never published.

ข้อกำหนดการเรียกใช้
ผลตัดสินล่าสุดของโมเดลหนึ่งตัว ให้ใช้ฟังก์ชันนี้เมื่ออยู่ใน set การคืน false หมายถึง "โมเดลตัวนี้ไม่เคยเผยแพร่ผลเลย" ซึ่งไม่เหมือนกับ "เงียบอยู่" (สมาชิกที่เคยเผยแพร่ครั้งหนึ่งแล้วเงียบไปยังคืนค่า true พร้อม seq ที่ค้างเก่า; หน้านี้สร้างตัวจับเวลาความเงียบรายแถวขึ้นจากความเก่าของ seq, page_edge_ai.c:728-739) index ต้องเป็นดัชนีใน registry จริง ๆ ห้ามเป็นดัชนีเทียมของ set — ให้เอารายชื่อสมาชิกมาจาก ai_engine_set_members() (set ที่ active อยู่) หรือ ai_engine_set_models() (set ใด ๆ)
