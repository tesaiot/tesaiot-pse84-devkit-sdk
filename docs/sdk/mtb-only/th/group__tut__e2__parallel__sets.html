สั่งให้หลายโมเดลทำงานพร้อมกันในฐานะ set อ่านผลตัดสินจาก set โดยไม่ทำให้การตรวจจับหายไป และรู้จักช่วงตั้งตัว (settle) ที่ผลตัดสินถูกกันไว้ไม่กี่วินาทีหลังจาก set เริ่มทำงาน ประโยคที่สำคัญที่สุดเพียงประโยคเดียว: ai_engine_snapshot() ใช้ไม่ได้ภายใน set

ลำดับการทำงานของเฟิร์มแวร์

ค่าคงที่ของ set (ai_engine.h): MIC = 255, ROOM = 254, INTRUDER = 253, ALL = 252 และ AI_PARALLEL_FIRST = ALL ส่วนชื่อเรียกเดิม 13/14/15 แปลงเป็น 253/254/255 (บท E1) เครื่องยนต์จะยอมรับดัชนีของ set ก็ต่อเมื่ออิมเมจนั้น build พร้อมโมเดลไมโครโฟนอย่างน้อยหนึ่งตัว มิฉะนั้น ai_engine_start() คืนค่า false

สมาชิกของ set ai_engine_set_models() คืนรายชื่อสมาชิกที่มีผลอยู่: หากเคยกำหนดสมาชิกภาพแบบชัดแจ้งด้วย ai_engine_set_define() รายการนั้นจะใช้แทนรายการที่คอมไพล์มา มิฉะนั้นจึงใช้รายการที่คอมไพล์มา โมเดลที่ init() ล้มเหลวไปครั้งหนึ่งไม่ถูกตัดออกจาก set ตลอดรอบการบูต การ start set ครั้งถัดไปจะลองโมเดลนั้นอีกครั้ง

ขั้นที่ 1 — ดูรายชื่อ set ที่หน้าจอมีให้ (ทั้งสอง variant)

บนหน้าจอ ให้เปิดดรอปดาวน์เลือกโมเดลบนหน้า Edge AI แถวของ set จะถูกเพิ่มเข้ามาก็ต่อเมื่อ set นั้นมีสมาชิกอย่างน้อย 2 ตัว และ ai_engine_set_name() คืนชื่อที่ไม่ใช่ NULL
