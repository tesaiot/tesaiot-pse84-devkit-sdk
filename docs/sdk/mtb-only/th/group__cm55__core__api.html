Detailed Description

cm55_core คือตัวควบคุมจอแสดงผลของ CM55 พร้อมกับโมดูลระดับหน้าจอที่คอมไพล์รวมไปกับมันเป็น archive (.a คือไฟล์ไลบรารีแบบสแตติก) ที่คอมไพล์มาแล้วเพียงตัวเดียว คือ libbento_cm55.a (template/lib/cm55_core/; ชื่อ libbento_cm55_core.a ไม่มีอยู่จริง — ตรวจยืนยันด้วยการไล่รายชื่อในไดเรกทอรี) dist/cm55_core/PROVENANCE.txt ระบุไฟล์ซอร์สไว้ 5 ไฟล์ ซึ่งไม่มีไฟล์ใดส่งมอบมาในเทมเพลตเลย ได้แก่ tesaiot_display.c (การเปิดใช้งาน GFXSS / vg_lite / LVGL และ GFX task), deepcraft_task.c (ฝั่งคู่ของ model link), page_edge_ai.c (หน้า hub ของ Edge AI), hsm_provision_ui.c (overlay สำหรับ enrol / protect) และ wifi_saved.c (เครือข่าย WiFi ที่บันทึกไว้ใน OPTIGA NVM) ส่วนที่ส่งมอบมามีเฉพาะ header เท่านั้น ได้แก่ tesaiot_display.h, deepcraft_task.h, page_edge_ai.h, hsm_provision_ui.h, wifi_saved.h และ bento_secure_undeclared.h ที่ถูกสร้างขึ้นอัตโนมัติ

variant ที่ใช้ได้
mtb-mpy และ mtb-only

CM55 ไม่ขึ้นกับ variant ทุกรายการในหน้านี้ใช้ได้กับ zip ทั้งสองชุด
