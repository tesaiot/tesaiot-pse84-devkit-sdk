หน้า UI และ IPC » CM55 Core (libbento_cm55.a) » ข้อมูลวินิจฉัยและ symbol ที่ไม่มีการประกาศ

bento_secure_undeclared.h ที่ถูกสร้างขึ้นอัตโนมัติ ระบุ symbol ที่ export ออกมา 5 ตัวไว้ว่า "exported, but no declaration found in the tree" ได้แก่ calculate_idle_percentage, disp_touch_i2c_controller_context, g_tesaiot_display_diag, rtos_cm55_gfx_task_handle, tesaiot_display_ready ผู้เรียกจริงในเทมเพลตรับมือเรื่องนี้ด้วยการเขียน extern ของตัวเองไว้ที่จุดที่ใช้งาน — cm55_sensor_poll.c:45 สำหรับ context ของ I2C, main.c:138 และ radar_task.c:580 สำหรับ flag บอกความพร้อม, lv_conf.h:973 สำหรับฟังก์ชันคำนวณเวลาว่าง — และนั่นคือรูปแบบที่ต้องคัดลอกไปใช้กับ symbol 3 ตัวนั้น

2 ตัวจาก 5 ตัวนี้ต้องมีการแก้ให้ถูก ซึ่งเป็นสิ่งที่การตรวจรอบตัวอย่างที่เขียนขึ้นเองพบ และหน้านี้ระบุไว้เป็นข้อเท็จจริง: g_tesaiot_display_diag และ rtos_cm55_gfx_task_handle มีการประกาศอยู่จริง ใน tesaiot_display.h ที่ส่งมอบมา (extern TaskHandle_t rtos_cm55_gfx_task_handle; และ extern volatile tesaiot_display_diag_t g_tesaiot_display_diag;) ข้อความ "no declaration found" ที่ตัวสร้างรายงานไว้จึงผิดสำหรับ 2 ตัวนี้ การ include tesaiot_display.h ก็เพียงพอแล้ว และการเขียน extern ด้วยมืออีกชุดหนึ่งที่มีชนิดต่างออกไปจะกลายเป็นการประกาศที่ขัดกัน ข้อเท็จจริงทั้ง 2 ข้อเป็นจริงพร้อมกัน: รายการที่ถูกสร้างขึ้นระบุว่ามี 5 ตัว ส่วน header ประกาศไว้ 2 ตัวในนั้น
