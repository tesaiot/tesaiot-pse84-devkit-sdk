mtb-mpy and mtb-only

Flag gate (read first)

Every symbol in this module is compiled out of the default build: ENABLE_PAGE_BENTO_BUDDY ?= 0 (proj_cm33_ns/Makefile:64, :305). The BLE bring-up block in proj_cm33_ns/main.c, including the [boot] Asserting WL_REG_ON prints, sits inside #if ENABLE_PAGE_BENTO_BUDDY (main.c:36, :325). Every example and every verify step on these topics presumes a rebuild with ENABLE_PAGE_BENTO_BUDDY=1 after make getlibs; the Makefile stops with $(error ...) at :353-359 if the BT libraries are missing. The module is "both variants" in the BENTO_HAS_MPY sense only — the flag, not the variant, decides whether it exists.

Long-form notes — what ships as source, the header packaging gap, snippet sources per variant, and the row classes every entry uses — are under Usage notes.
