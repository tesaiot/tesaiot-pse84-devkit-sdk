Detailed Description

Five functions for sets — several models listening to the same sensor data. Constants, the legacy 13/14/15 translation and the two hard facts (ALL has no definable slot; ai_engine_snapshot() loses detections in a set) are in Set pseudo-indices and the legacy translation.

Members of any set, in registry order; explicit membership wins outright.

Members of a set, in registry order. Returns how many were written.

Contract
Writes the members of any set, in registry order, and returns how many were written (0 for a non-set index). Precedence: an explicit membership from ai_engine_set_define() wins outright over the compiled name-match list (ai_engine.c:1146-1149). Resolution is rebuilt on every entry to the set, never cached, so a model whose init() failed once is not exiled for the boot. Inside a render, take ai_engine_active() once and pass that value here — the deepcraft task can start/stop from another task mid-render, and re-reading it would let the set used for the layout tag disagree with the set the rows were sized from.

Registry indices of the ACTIVE set's members; test each member's sensor.

Registry indices of the ACTIVE SET's members, up to max, whatever sensor each one reads – not microphone models. Returns the count. Callers that iterate this must test desc->sensor before doing anything sensor-specific with an entry.

Contract
Registry indices of the ACTIVE set's members only, up to max; returns the count. Members may read any sensor — not only the microphone — so a caller that does anything sensor-specific must test desc->sensor on each ai_engine_model() entry first. This is the fan-out the MicroPython Q_RESULT path uses with ai_engine_snapshot_model() and ai_result_top_positive() to report the loudest positive member.

const uint8_t * members,

Give a set an explicit run-time membership; task context, all-or-nothing.

Give a set an explicit membership at run time, replacing the compiled one. Task context. Undefined sets keep their compiled membership exactly.

Contract
Gives a set an explicit run-time membership, replacing the compiled one. Task context only — it takes taskENTER_CRITICAL() around the publish (ai_engine.c:1059-1075). 1..8 members. All-or-nothing: every index is validated and one bad index refuses the whole definition. AI_PARALLEL_ALL (252) has no slot — the call always returns -1 for it (set_slot(), ai_engine.c:1040-1048, maps only INTRUDER/ROOM/MIC). There is no ack event: the only acknowledgement is reading back ai_engine_set_members_defined(). The MicroPython edge_ai.set_define() drives this as a three-command build (SET_BEGIN, one SET_ADD per member paced at 5 ms, SET_COMMIT) applied whole on commit — a dropped ADD is caught only by the Q_SET read-back. Why it exists: compiled sets match by name, so a staged (uploaded) model can join a watch only through an explicit definition (ai_engine.c:1092-1127).
