Learning goal

Run several models at once as a set, read a verdict from the set without losing detections, and recognise the settle period that withholds verdicts for a few seconds after a set starts. The single most important sentence: ai_engine_snapshot() is not valid inside a set.

Firmware sequence

Set constants (ai_engine.h): MIC = 255, ROOM = 254, INTRUDER = 253, ALL = 252, AI_PARALLEL_FIRST = ALL. The legacy 13/14/15 aliases resolve to 253/254/255 (Chapter E1). The engine accepts a set index only in an image built with at least one microphone model; otherwise ai_engine_start() returns false.

Set members. ai_engine_set_models() returns the members in effect: an explicit membership given with ai_engine_set_define() replaces the compiled one; otherwise the compiled membership applies. A model whose init() failed once is not dropped from the set for the boot — the next start of the set tries it again.

Custom membership — edge_ai.set_define(set, [i, j, ...]) resolves the legacy index, sends SET_BEGIN, one SET_ADD per member and SET_COMMIT, then reads the membership back with Q_SET — the read-back is the only thing that catches a dropped ADD. CM55 applies the definition whole on SET_COMMIT. The C side does the same in two calls, and the read-back is the only acknowledgement:

static const uint8_t members[] = { 0u, 2u }; /* registry indices */
if (ai_engine_set_define(AI_PARALLEL_INTRUDER, members, 2u) < 0) {
/* refused whole: a bad index, 0 or more than 8 members, or AI_PARALLEL_ALL */
}
uint8_t got[8];
uint32_t n = ai_engine_set_members_defined(AI_PARALLEL_INTRUDER, got, 8u);
/* n == 2 and got[] == members[] is the confirmation */

Step by step

Step 1 — Enumerate the sets the page offers (both variants)

On screen, open the model dropdown on the Edge AI page. Rows for sets are added only when the set has at least two members and ai_engine_set_name() returns a non-NULL name.

What you should observe. Set rows (Sound Watch, Room Presence, Intruder Watch, All Models) appear after the compiled single models. A set with fewer than two members in this image is simply absent — that is a build-content fact, not a fault.

Step 2 — Select a set and watch the settle period

>>> edge_ai.select(255) # MIC set; 15 is the legacy alias
True
>>> edge_ai.result()
>>> edge_ai.result()

What you should observe. For the first seconds result() returns None — class_count == 0 — while the set's inputs settle. On screen the verdict label reads filling windows lu%% with the percentage climbing, and the badge shows Loading. On the C side the calls are ai_engine_mic_settling() / ai_engine_mic_settle_pct():

}

ai_engine_snapshot_model() returning false means "never published", which is not the same as "silent"; the index must be a real registry index, never a set pseudo-index.

Step 4 — Define your own membership

>>> edge_ai.set_define(253, [0, 2])
>>> edge_ai.select(253)
True

What you should observe. set_define returns after the Q_SET read-back confirms every member; a dropped ADD shows up as a shorter list, and the whole definition is refused if any index is invalid (all-or-nothing). Membership is 1..8 entries. set_define(252, ...) always fails — AI_PARALLEL_ALL is every registered model by definition and cannot be redefined; only INTRUDER, ROOM and MIC can.

Step 5 — Read active() once per render (C side)

Traps

Warning
The snapshot-in-set hazard. ai_engine_snapshot() returns the most recent verdict from any model. In a set, a cough detected at 0.94 is followed by three "unlabelled" verdicts from the other members before a 10 Hz reader sees it — the detection is not late, it is gone. Use ai_engine_snapshot_model() per member and reduce. A set is any index in the range [AI_PARALLEL_FIRST, AI_PARALLEL_MIC]; test the range, not == AI_PARALLEL_MIC, which covers only one of the four sets.
set_define is task context only. Never call it from an ISR or from the pipe callback.
ai_engine_model_count() leads the rows. ai_engine_model(i) may still return NULL for an index with no row behind it — continue, do not abort:
for (uint32_t i = 0u; i < ai_engine_model_count(); i++) {
const ai_model_desc_t *d = ai_engine_model(i);
if (d == NULL) {
continue; /* no row here: skip it, keep going */
}
/* ... use d ... */
}
