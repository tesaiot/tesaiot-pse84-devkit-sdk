Detailed Description

The storage/credentials reference: the six lfs_wifi_creds_* functions, their exemplars cited against storage_c/lfs_wifi_creds_c.c and sensor_auto_task.c — both of which the mtb-only zip ships as source. This reference is homed here, under Storage & Credentials, on both variant sites at the same URL (RED_IA_REVIEW P1-6; the mpy_secure section cross-links here instead of carrying its own copy). The two-implementation panel (archive implementation vs lfs_wifi_creds_c.c), with the byte-compatible on-disk format as the shared contract, is The two implementations, one on-disk contract.

On mtb-only, libbento_mpy.a is not linked and the mpy_secure module contributes no symbols; these six names are the one exception, re-provided by the shipped C store. On mtb-mpy the same six names come from lfs_wifi_creds.c inside libbento_mpy.a. The shipped C implementation is quoted in full on the reference pages — it is short enough to be its own specification.
