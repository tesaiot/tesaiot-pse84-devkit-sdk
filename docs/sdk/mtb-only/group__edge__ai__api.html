Detailed Description

Runs ONE DEEPCRAFT model — or one parallel set — at a time on CM55 (TFLite-Micro + Ethos-U55) and publishes a result snapshot for the UI and the MicroPython model link.

The archive exports 39 symbols (dist/edge_ai/api.txt): 37 API functions declared in ai_engine.h and ai_model_staged.h, plus printf and puts, which are not API at all but a link-time hazard every CM55 consumer must know about (printf/puts link hazard).

Two layers of access, and they do not overlap. C code compiled into proj_cm55 calls ai_engine_* and ai_model_staged_* directly — and every shipped caller of this surface is itself inside the prebuilt libbento_cm55.a. MicroPython runs on CM33_NS and cannot call ai_engine_* at all: it reaches this module only over the IPC model link — edge_ai.select(), edge_ai.result(), edge_ai.diag() and the rest, whose semantics are the ones documented here. The full statement, including where every example in this module comes from, is Two layers of access — who can call what.

The select → confirm → start discipline

The engine keeps two indices, and the whole module hinges on the difference:

Query Engine field Meaning
ai_engine_requested() s_active the model REQUESTED by the last ai_engine_start() — set synchronously
ai_engine_active() s_current the model LOADED — flips only after the inference task's cold init() returns

A cold TFLite-Micro + Ethos-U55 bring-up runs synchronously inside the model's init(), so active() lags requested() by the whole cold-init window (the MicroPython side budgets 15 s for it). Three rules follow:

  1. Select, then confirm, then rely on start. After ai_engine_start(), poll: active() == want means loaded. Otherwise poll requested() — once requested() == want has been seen, a later requested() < 0 can only mean the model's init() failed, so fail fast instead of waiting the ceiling.
  2. Never gate a fallback on ai_engine_active(). The recorded bug: a page tap set s_active = sel and posted START; a guard that read s_current (still -1 that tick) fired ai_engine_start(0) and clobbered the selection back to model 0 — "select Radar, Load, get Motion" (ai_engine.c:1868-1873, deepcraft_task.c:634-640). Guard on ai_engine_requested().
  3. ai_engine_init() must precede ai_engine_start(); it is idempotent, so the shipped idiom re-calls it immediately before every start.

Set pseudo-indices (252..255) and the legacy 13/14/15 translation are covered in Set pseudo-indices and the legacy translation.
