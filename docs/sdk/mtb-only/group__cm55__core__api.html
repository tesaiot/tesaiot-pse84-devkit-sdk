Detailed Description

cm55_core is the CM55 display controller and the page-level modules that were compiled with it into one prebuilt archive, libbento_cm55.a (template/lib/cm55_core/; the name libbento_cm55_core.a does not exist — verified by listing the directory). dist/cm55_core/PROVENANCE.txt names five source files, none of which ships in the template: tesaiot_display.c (GFXSS / vg_lite / LVGL bring-up and the GFX task), deepcraft_task.c (the model-link peer), page_edge_ai.c (the Edge AI hub page), hsm_provision_ui.c (the enrol / protect overlays) and wifi_saved.c (saved WiFi networks in OPTIGA NVM). Only the headers ship: tesaiot_display.h, deepcraft_task.h, page_edge_ai.h, hsm_provision_ui.h, wifi_saved.h, plus the generated bento_secure_undeclared.h.

Variant
mtb-mpy and mtb-only

CM55 is variant-agnostic; every entry applies to both zips.
